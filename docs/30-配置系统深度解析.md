## 概述

OpenCode 配置系统采用分层架构，支持多种配置来源、自动发现、运行时验证和热重载。配置使用 JSON/JSONC 格式，通过 Zod schema 进行严格验证，并生成 JSON Schema 用于 LSP 支持。

### 核心特性

- **分层加载**: 支持多来源配置，按优先级合并
- **自动发现**: 从多个目录自动扫描配置和扩展
- **严格验证**: Zod schema 运行时验证，JSON Schema for LSP
- **环境变量**: 支持 `{env:VAR}` 和 `{file:path}` 语法
- **热重载**: 文件变化时自动重新加载配置
- **数组合并**: 特定字段（如 plugin、instructions）使用连接而非替换
- **向后兼容**: 支持旧的 TOML 配置格式迁移

## 配置文件格式

### 主要格式

#### JSON (推荐)

**文件扩展名**: `.json`

**示例**:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "anthropic/claude-sonnet-4",
  "default_agent": "build",
  "plugin": ["my-plugin@1.0.0", "@scope/another-plugin"]
}
```

#### JSONC (带注释的 JSON)

**文件扩展名**: `.jsonc`

**特点**:

- 支持 `//` 单行注释
- 支持 `/* */` 多行注释
- 支持尾随逗号
- 完全兼容 JSON 语法

**示例**:

```jsonc
{
  // OpenCode 配置
  "$schema": "https://opencode.ai/config.json",

  // 默认模型
  "model": "anthropic/claude-sonnet-4",

  // 默认代理
  "default_agent": "build",

  // 插件列表
  "plugin": [
    "my-plugin@1.0.0", // 第一个插件
    "@scope/another-plugin", // 作用域包
  ],

  // 权限配置
  "permission": {
    "read": "allow",
    "edit": {
      "*": "allow",
      "*.env": "ask",
    },
  },
}
```

**代码位置**: `/packages/opencode/src/config/config.ts:180-202` (parseJsonc 调用)

**文件扩展名**: 无扩展名或 `.toml`

```typescript
export const state = Instance.state(async () => {
  const auth = await Auth.all()
  let result: Info = {}

  // 1. 加载远程 well-known 配置
  for (const [key, value] of Object.entries(auth)) {
    if (value.type === "wellknown") {
      process.env[value.key] = value.token
      const response = await fetch(`${key}/.well-known/opencode`)
      const wellknown = (await response.json()) as any
      const remoteConfig = wellknown.config ?? {}
      if (!remoteConfig.$schema) {
        remoteConfig.$schema = "https://opencode.ai/config.json"
      }
      result = mergeConfigConcatArrays(result, await load(...))
    }
  }

  // 2. 加载全局用户配置
  result = mergeConfigConcatArrays(result, await global())

  // 3. 加载自定义配置路径
  if (Flag.OPENCODE_CONFIG) {
    result = mergeConfigConcatArrays(result, await loadFile(Flag.OPENCODE_CONFIG))
  }

  // 4. 加载项目配置
  if (!Flag.OPENCODE_DISABLE_PROJECT_CONFIG) {
    for (const file of ["opencode.jsonc", "opencode.json"]) {
      const found = await Filesystem.findUp(file, Instance.directory, Instance.worktree)
      for (const resolved of found.toReversed()) {
        result = mergeConfigConcatArrays(result, await loadFile(resolved))
      }
    }
  }

  // 5. 加载内联配置内容
  if (Flag.OPENCODE_CONFIG_CONTENT) {
    result = mergeConfigConcatArrays(result, JSON.parse(Flag.OPENCODE_CONFIG_CONTENT))
  }

  // 6. 扫描 .opencode/ 目录中的扩展配置
  for (const dir of unique(directories)) {
    // 加载命令、代理、插件等
    result.command = mergeDeep(result.command ?? {}, await loadCommand(dir))
    result.agent = mergeDeep(result.agent, await loadAgent(dir))
    result.plugin.push(...(await loadPlugin(dir)))
  }

  return { config: result, directories }
})
```

### 验证流程

**代码位置**: `/packages/opencode/src/config/config.ts:1204-1228`

```typescript
async function load(text: string, configFilepath: string) {
  const original = text

  // 1. 环境变量替换
  text = text.replace(/\{env:([^}]+)\}/g, (_, varName) => {
    return process.env[varName] || ""
  })

  // 2. 文件引用替换
  const fileMatches = text.match(/\{file:[^}]+\}/g)
  if (fileMatches) {
    for (const match of fileMatches) {
      let filePath = match.replace(/^\{file:/, "").replace(/\}$/, "")
      if (filePath.startsWith("~/")) {
        filePath = path.join(os.homedir(), filePath.slice(2))
      }
      const resolvedPath = path.isAbsolute(filePath) ? filePath : path.resolve(path.dirname(configFilepath), filePath)
      const fileContent = (await Bun.file(resolvedPath).text()).trim()
      text = text.replace(match, JSON.stringify(fileContent).slice(1, -1))
    }
  }

  // 3. JSONC 解析
  const errors: JsoncParseError[] = []
  const data = parseJsonc(text, errors, { allowTrailingComma: true })

  if (errors.length) {
    // 生成详细的错误报告
    const lines = text.split("\n")
    const errorDetails = errors
      .map((e) => {
        const beforeOffset = text.substring(0, e.offset).split("\n")
        const line = beforeOffset.length
        const column = beforeOffset[beforeOffset.length - 1].length + 1
        const problemLine = lines[line - 1]

        const error = `${printParseErrorCode(e.error)} at line ${line}, column ${column}`
        if (!problemLine) return error

        return `${error}\n   Line ${line}: ${problemLine}\n${"".padStart(column + 9)}^`
      })
      .join("\n")

    throw new JsonError({
      path: configFilepath,
      message: `\n--- JSONC Input ---\n${text}\n--- Errors ---\n${errorDetails}\n--- End ---`,
    })
  }

  // 4. Zod schema 验证
  const parsed = Info.safeParse(data)
  if (parsed.success) {
    // 自动添加 $schema
    if (!parsed.data.$schema) {
      parsed.data.$schema = "https://opencode.ai/config.json"
      const updated = original.replace(/^\s*\{/, '{\n  "$schema": "https://opencode.ai/config.json",')
      await Bun.write(configFilepath, updated).catch(() => {})
    }

    // 解析插件路径
    if (parsed.data.plugin) {
      for (let i = 0; i < parsed.data.plugin.length; i++) {
        const plugin = parsed.data.plugin[i]
        try {
          parsed.data.plugin[i] = import.meta.resolve!(plugin, configFilepath)
        } catch (err) {}
      }
    }

    return parsed.data
  }

  // 5. 验证失败处理
  throw new InvalidError({
    path: configFilepath,
    issues: parsed.error.issues,
  })
}
```

```typescript
text = text.replace(/\{env:([^}]+)\}/g, (_, varName) => {

```

**用途**:

- 敏感信息（API 密钥）不应存储在配置文件中
- 支持不同环境（开发、测试、生产）
- 可以通过 shell 环境变量设置

**环境变量设置**:

```bash

export OPENAI_BASE_URL="https://api.openai.com/v1"

# 启动 OpenCode
opencode
```

#### 2. 文件引用

**语法**: `{file:RELATIVE_OR_ABSOLUTE_PATH}`

**示例**:

```jsonc
{
  "provider": {
    "openai": {
      "options": {
        "apiKey": "{file:~/.secrets/openai-key.txt}",
        "baseURL": "{file:./config/base-url.txt}",
      },
    },
  },
  "instructions": ["{file:./docs/project-guidelines.md}", "{file:~/.opencode/global-instructions.md}"],
}
```

**替换逻辑**:

**代码位置**: `/packages/opencode/src/config/config.ts:1143-1178`

```typescript
const fileMatches = text.match(/\{file:[^}]+\}/g)
if (fileMatches) {
  const configDir = path.dirname(configFilepath)
  const lines = text.split("\n")

  for (const match of fileMatches) {
    const lineIndex = lines.findIndex((line) => line.includes(match))
    if (lineIndex !== -1 && lines[lineIndex].trim().startsWith("//")) {
      continue // 跳过注释行
    }

    let filePath = match.replace(/^\{file:/, "").replace(/\}$/, "")

    // 处理 ~ 路径
    if (filePath.startsWith("~/")) {
      filePath = path.join(os.homedir(), filePath.slice(2))
    }

    // 解析相对/绝对路径
    const resolvedPath = path.isAbsolute(filePath) ? filePath : path.resolve(configDir, filePath)

    // 读取文件内容
    const fileContent = (await Bun.file(resolvedPath).text()).trim().catch((error) => {
      const errMsg = `bad file reference: "${match}"`
      if (error.code === "ENOENT") {
        throw new InvalidError(
          {
            path: configFilepath,
            message: errMsg + ` ${resolvedPath} does not exist`,
          },
          { cause: error },
        )
      }
      throw new InvalidError(
        {
          path: configFilepath,
          message: errMsg,
        },
        { cause: error },
      )
    })

    // 转义并替换（去除引号）
    text = text.replace(match, JSON.stringify(fileContent).slice(1, -1))
  }
}
```

**路径解析规则**:

- `~` → 用户主目录
- 相对路径 → 相对于配置文件所在目录
- 绝对路径 → 直接使用

**错误处理**:

- 文件不存在 → 抛出 `InvalidError`
- 文件内容自动 trim()
- 多行内容会保留（包括换行符）

```typescript
    // 订阅项目目录（实验性）
    if (Flag.OPENCODE_EXPERIMENTAL_FILEWATCHER) {
      const pending = w.subscribe(Instance.directory, subscribe, {
        ignore: [...FileIgnore.PATTERNS, ...(cfg.watcher?.ignore ?? [])],
        backend,
      })
      const sub = await withTimeout(pending, SUBSCRIBE_TIMEOUT_MS).catch(() => undefined)
      if (sub) subs.push(sub)
    }

    // 订阅 Git 目录
    const vcsDir = await $`git rev-parse --git-dir`.text()
    if (vcsDir) {
      const gitDirContents = await readdir(vcsDir)
      const ignoreList = gitDirContents.filter((entry) => entry !== "HEAD")
      const pending = w.subscribe(vcsDir, subscribe, {
        ignore: ignoreList,
        backend,
      })
      const sub = await withTimeout(pending, SUBSCRIBE_TIMEOUT_MS).catch(() => undefined)
      if (sub) subs.push(sub)
    }

    return { subs }
  },
  async (state) => {
    // 清理：取消所有订阅
    if (!state.subs) return
    await Promise.all(state.subs.map((sub) => sub?.unsubscribe()))
  },
)
```

## 合并策略

### 深度合并

OpenCode 使用 `remeda` 的 `mergeDeep` 函数进行深度合并。

**代码位置**: `/packages/opencode/src/config/config.ts:8`

```typescript
import { mergeDeep } from "remeda"
```

**深度合并规则**:

```typescript
// 示例：嵌套对象合并
const target = {
  agent: {
    build: { temperature: 0.7 },
    plan: { temperature: 0.1 }
  }
}

const source = {
  agent: {
    build: { steps: 10 },
    reviewer: { temperature: 0.3 }
  }
}

const merged = mergeDeep(target, source)
// 结果:
{
  agent: {
    build: { temperature: 0.7, steps: 10 },  // 合并
    plan: { temperature: 0.1 },             // 保留
    reviewer: { temperature: 0.3 }         // 新增
  }
}
```

### 数组连接（特殊合并）

某些字段使用**连接**而非替换。

**代码位置**: `/packages/opencode/src/config/config.ts:36-44`

```typescript
function mergeConfigConcatArrays(target: Info, source: Info): Info {
  const merged = mergeDeep(target, source)

  // plugin 列表：去重后连接
  if (target.plugin && source.plugin) {
    merged.plugin = Array.from(new Set([...target.plugin, ...source.plugin]))
  }

  // instructions 列表：去重后连接
  if (target.instructions && source.instructions) {
    merged.instructions = Array.from(new Set([...target.instructions, ...source.instructions]))
  }

  return merged
}
```

**示例**:

```typescript
// 目标配置
const target = {
  plugin: ["plugin-a@1.0.0"],
  instructions: ["Always write tests"],
}

// 源配置
const source = {
  plugin: ["plugin-b@2.0.0", "plugin-a@1.0.0"], // 重复的插件
  instructions: ["Use TypeScript", "Always write tests"], // 重复的指令
}

// 合并结果
const merged = mergeConfigConcatArrays(target, source)
// {
//   plugin: ["plugin-a@1.0.0", "plugin-b@2.0.0"],  // 去重
//   instructions: ["Always write tests", "Use TypeScript"]  // 去重
// }
```

### 替换行为

大多数字段使用**替换**行为（后者覆盖前者）：

```typescript
// 目标
const target = { model: "anthropic/claude-3", temperature: 0.7 }

// 源
const source = { model: "anthropic/claude-4", temperature: 0.5 }

// 合并
const merged = mergeDeep(target, source)
// { model: "anthropic/claude-4", temperature: 0.5 }  // 完全覆盖
```

### 1. 配置文件选择

**推荐**: 使用 `.opencode/opencode.jsonc`

**原因**:

- 支持注释（更好的文档化）

- 位于项目目录，易于版本控制
