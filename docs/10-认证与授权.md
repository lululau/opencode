## 概述

OpenCode 的认证与授权系统提供了灵活的安全机制，用于管理对 AI 提供商、MCP 服务器和外部服务的访问。系统支持多种认证方式，包括 OAuth 2.0、API 密钥和自定义认证流程。

### 主要特性

- **多种认证方式**：支持 OAuth 2.0、API 密钥和 Well-known 认证
- **插件扩展**：通过插件系统支持自定义认证流程
- **MCP OAuth 集成**：为 MCP 服务器提供完整的 OAuth 2.0 支持
- **安全存储**：凭证以加密方式安全存储在本地
- **自动令牌刷新**：支持 OAuth 访问令牌的自动刷新
- **灵活配置**：支持环境变量、配置文件和命令行输入

## 核心概念

### Auth.Info（认证信息）

所有认证信息都遵循统一的类型定义：

```typescript
export namespace Auth {
  // OAuth 认证
  export const Oauth = z.object({
    type: z.literal("oauth"),
    refresh: z.string(), // 刷新令牌
    access: z.string(), // 访问令牌
    expires: z.number(), // 过期时间（时间戳）
    accountId: z.string().optional(), // 账户 ID
    enterpriseUrl: z.string().optional(), // 企业版 URL
  })

  // API 密钥认证
  export const Api = z.object({
    type: z.literal("api"),
    key: z.string(), // API 密钥
  })

  // Well-known 认证
  export const WellKnown = z.object({
    type: z.literal("wellknown"),
    key: z.string(), // 密钥名称（环境变量名）
    token: z.string(), // 令牌值
  })

  // 联合类型
  export const Info = z.discriminatedUnion("type", [Oauth, Api, WellKnown])
}
```

## 认证类型

### 1. OAuth 2.0 认证

OAuth 2.0 是 OpenCode 推荐的认证方式，提供更好的安全性和用户体验。

#### OAuth 流程

OpenCode 实现了标准的 OAuth 2.0 授权码流程（Authorization Code Flow）：

```
1. 用户发起登录
   └─> 生成 PKCE 验证器（code_verifier）
       └─> 生成 code_challenge（SHA-256）

2. 打开授权 URL
   └─> 用户在浏览器中授权
       └─> 授权服务器返回 authorization code

3. 交换访问令牌
   └─> 使用 authorization code + PKCE 验证器
       └─> 获取 access_token 和 refresh_token

4. 存储凭证
   └─> 保存到 auth.json
       └─> 设置文件权限为 600（仅用户可读写）

5. 使用凭证
   └─> 在请求中添加 Authorization: Bearer <token>
       └─> 令牌过期时自动刷新
```

#### PKCE（Proof Key for Code Exchange）

为了增强安全性，OpenCode 使用 PKCE 扩展：

```typescript
// 生成 PKCE 验证器
async function generatePKCE(): Promise<PkceCodes> {
  const verifier = generateRandomString(43)
  const encoder = new TextEncoder()
  const data = encoder.encode(verifier)
  const hash = await crypto.subtle.digest("SHA-256", data)
  const challenge = base64UrlEncode(hash)
  return { verifier, challenge }
}

// 生成授权 URL
function buildAuthorizeUrl(redirectUri: string, pkce: PkceCodes): string {
  const params = new URLSearchParams({
    response_type: "code",
    client_id: CLIENT_ID,
    redirect_uri: redirectUri,
    scope: "openid profile email offline_access",
    code_challenge: pkce.challenge,
    code_challenge_method: "S256",
  })
  return `${ISSUER}/oauth/authorize?${params.toString()}`
}
```

#### 令牌刷新

当访问令牌过期时，系统自动使用刷新令牌获取新的访问令牌：

```typescript
// 检查令牌是否过期
if (currentAuth.expires < Date.now()) {
  const tokens = await refreshAccessToken(currentAuth.refresh)
  await Auth.set(providerID, {
    type: "oauth",
    access: tokens.access_token,
    refresh: tokens.refresh_token,
    expires: Date.now() + tokens.expires_in * 1000,
  })
}
```

### 3. Well-known 认证

Well-known 认证用于集成自定义的 OpenCode 服务端：

```typescript
// 1. 发现认证端点
const wellknown = await fetch(`${url}/.well-known/opencode`).then((r) => r.json())

// 2. 执行认证命令

  cmd: wellknown.auth.command,
  stdout: "pipe",

// 3. 获取令牌
```

凭证存储在用户数据目录的 `auth.json` 文件中：

## 提供商认证

### 认证发现

OpenCode 自动发现每个提供商支持的认证方式：

```typescript
export namespace ProviderAuth {
  // 获取所有提供商的认证方法
  export async function methods(): Promise<Record<string, Method[]>> {
    const plugins = await Plugin.list()
    const methods = {}

    for (const plugin of plugins) {
      if (plugin.auth?.provider) {
        methods[plugin.auth.provider] = plugin.auth.methods.map((m) => ({
          type: m.type,
          label: m.label,
        }))
      }
    }

    return methods
  }
}
```

## 插件认证

OpenCode 的插件系统支持自定义认证流程，允许第三方提供商集成。

### 插件 Auth Hook

插件可以通过 `auth` hook 提供认证功能：

```typescript
export interface Hooks {
  auth?: {
    provider: string // 提供商 ID
    methods: AuthMethod[] // 支持的认证方法
    loader?: (getAuth: () => Promise<Auth.Info>, provider: Provider.Info) => Promise<object> // 加载认证后的选项
  }
}

export interface AuthMethod {
  type: "oauth" | "api"
  label: string // 显示名称
  prompts?: Prompt[] // 用户输入提示
  authorize?: (inputs: Record<string, string>) => Promise<AuthorizeResult>
}

export interface Prompt {
  key: string
  type: "text" | "select"
  message: string
  placeholder?: string
  options?: Array<{ label: string; value: string }>
  validate?: (value: string) => string | undefined
  condition?: (inputs: Record<string, string>) => boolean
}
```

#### OAuth 认证

```typescript
{
  type: "oauth",
```


### Loader Hook

Loader hook 允许插件在认证后修改提供商配置：

```typescript
{
  auth: {
    provider: "github-copilot",
    loader: async (getAuth, provider) => {
      const auth = await getAuth()
      if (auth.type !== "oauth") return {}

      // 为 OAuth 令牌添加模型过滤器
      return {
        modelFilter: (model) => model.id.startsWith("gpt-4")
      }
    }
  }
}
```

### 内置插件

#### Codex 插件

处理 OpenAI Codex OAuth 认证：

```typescript
// 位置: packages/opencode/src/plugin/codex.ts

export async function CodexAuthPlugin(input: PluginInput): Promise<Hooks> {
  return {
    auth: {
      provider: "openai",
      methods: [
        {
          type: "oauth",
          label: "ChatGPT Plus/Pro (Codex)",
          authorize: async () => {
            const { redirectUri } = await startOAuthServer()
            const pkce = await generatePKCE()
            const state = generateState()

            const authUrl = buildAuthorizeUrl(redirectUri, pkce, state)
            const callbackPromise = waitForOAuthCallback(pkce, state)

            return {
              url: authUrl,
              method: "auto",
              instructions: "Complete authorization in your browser...",
              callback: async () => {
                stopOAuthServer()
                const tokens = await callbackPromise

                // 提取 account ID
                const accountId = extractAccountId(tokens)

                return {
                  type: "success",
                  access: tokens.access_token,
                  refresh: tokens.refresh_token,
                  expires: Date.now() + tokens.expires_in * 1000,
                  accountId,
                }
              },
            }
          },
        },
      ],

      // Loader: 移除 dummy API key 并使用 OAuth 令牌
      async loader(getAuth, provider) {
        const auth = await getAuth()
        if (auth.type !== "oauth") return {}

        return {
          fetchOverride: async (request, init) => {
            // 使用 OAuth 令牌
            init.headers.set("authorization", `Bearer ${auth.access}`)

            // 添加账户 ID（如果存在）
            if (auth.accountId) {
              init.headers.set("ChatGPT-Account-Id", auth.accountId)
            }

            // 自动刷新令牌
            if (auth.expires < Date.now()) {
              const tokens = await refreshAccessToken(auth.refresh)
              await input.client.auth.set({
                type: "oauth",
                access: tokens.access_token,
                refresh: tokens.refresh_token,
                expires: Date.now() + tokens.expires_in * 1000,
                accountId: auth.accountId,
              })
              init.headers.set("authorization", `Bearer ${tokens.access_token}`)
            }

            return fetch(request, init)
          },
        }
      },
    },
  }
}
```

## MCP OAuth

MCP (Model Context Protocol) 服务器支持 OAuth 2.0 认证，OpenCode 提供完整的集成。

### OAuth 支持检测

远程 MCP 服务器默认支持 OAuth，除非明确禁用：

```typescript
// 配置示例
{
  "mcp": {
    "my-server": {
      "type": "remote",
      "url": "https://mcp.example.com",
      "oauth": false  // 明确禁用 OAuth
    },
    "oauth-server": {
      "type": "remote",
      "url": "https://oauth.example.com"
      // oauth: true  // 默认启用
    }
  }
}
```

MCP OAuth 可以自定义客户端信息：

```typescript
interface McpOAuthConfig {

// 配置示例
{
  "mcp": {
    "custom-oauth-server": {
      "type": "remote",

      "oauth": {
        "clientId": "my-client-id",

        "scope": "read write"
      }

```

### OAuth 提供商实现

```typescript
export class McpOAuthProvider implements OAuthClientProvider {
  // 客户端元数据
  get clientMetadata(): OAuthClientMetadata {
    return {
      redirect_uris: [`${this.callbackUrl}`],
      grant_types: ["authorization_code", "refresh_token"],
      response_types: ["code"],
      token_endpoint_auth_method: this.config.clientSecret ? "client_secret_post" : "none",
    }
  }

  // 存储令牌
  async saveTokens(tokens: OAuthTokens): Promise<void> {
    await McpAuth.updateTokens(this.mcpName, tokens)
  }

  // 存储客户端信息（动态注册）
  async saveClientInformation(info: OAuthClientInformationFull): Promise<void> {
    await McpAuth.updateClientInfo(this.mcpName, this.serverUrl, info)
  }
}
```

### OAuth 流程

```
1. 发起认证
   opencode mcp auth my-server
   └─> 生成 PKCE 验证器
       └─> 启动回调服务器 (http://localhost:1455/mcp/oauth/callback)
       └─> 尝试连接 MCP 服务器
       └─> 服务器返回 401 Unauthorized + WWW-Authenticate
       └─> 提取 authorization_url

2. 用户授权
   └─> 打开浏览器到 authorization_url
       └─> 用户完成授权
       └─> 重定向到回调 URL

3. 完成认证
   └─> 回调服务器接收 code + state
       └─> 验证 state
       └─> 调用 transport.finishAuth(code)
       └─> 存储 OAuth 令牌

4. 使用凭证
   └─> 后续请求自动使用 Bearer token
       └─> 令牌过期时自动刷新
```

## 安全实践

### 凭证存储安全

1. **文件权限**：`auth.json` 文件权限设置为 `0o600`，仅所有者可读写

```typescript
await fs.chmod(file.name, 0o600)
```

2. **环境变量优先**：环境变量优先于存储的凭证，避免硬编码敏感信息

```typescript
// 先检查环境变量
const envKey = process.env[provider.env]
if (envKey) return envKey

// 再检查存储的凭证
const auth = await Auth.get(providerID)
```

3. **临时密钥**：使用 PKCE 生成临时 code_verifier，不长期存储

### OAuth 安全

1. **PKCE**：使用 Proof Key for Code Exchange 防止授权码拦截

```typescript
// code_verifier 和 code_challenge 是一次性使用
const pkce = await generatePKCE()
```

2. **State 参数**：使用随机 state 参数防止 CSRF 攻击

```typescript
const state = generateState()
// 验证回调时检查 state
if (state !== storedState) throw new Error("State mismatch")
```

3. **HTTPS**：所有 OAuth 流程必须使用 HTTPS

```typescript
const ISSUER = "https://auth.openai.com"
```

4. **令牌刷新**：使用短期访问令牌和长期刷新令牌

```typescript
{
  access_token: "short-lived-token",
  refresh_token: "long-lived-token",
  expires_in: 3600  // 1 小时
}
```

### 认证错误处理

```typescript
export const AuthError = NamedError.create(
  "ProviderAuthError",
  z.object({
    providerID: z.string(),
    message: z.string(),
  }),
)
```

常见错误：

| 错误                              | 原因             | 解决方案             |
| --------------------------------- | ---------------- | -------------------- |
| `ProviderAuthOauthMissing`        | OAuth 流程未启动 | 重新调用 `authorize` |
| `ProviderAuthOauthCodeMissing`    | 缺少授权码       | 重新输入授权码       |
| `ProviderAuthOauthCallbackFailed` | 回调失败         | 检查网络连接，重试   |

### 插件认证处理

```typescript
async function handlePluginAuth(plugin: { auth: PluginAuth }, provider: string) {
  // 1. 选择认证方法
  let index = 0
  if (plugin.auth.methods.length > 1) {
    const method = await prompts.select({
      message: "Login method",
      options: plugin.auth.methods.map((x, i) => ({
        label: x.label,
        value: i.toString(),
      })),
    })
    index = parseInt(method)
  }

  const method = plugin.auth.methods[index]

  // 2. 收集用户输入
  const inputs: Record<string, string> = {}
  if (method.prompts) {
    for (const prompt of method.prompts) {
      const value = await prompts.text({
        message: prompt.message,
        placeholder: prompt.placeholder,
      })
      inputs[prompt.key] = value
    }
  }

  // 3. 执行认证
  if (method.type === "oauth") {
    const authorize = await method.authorize(inputs)
    if (authorize.url) {
      prompts.log.info("Go to: " + authorize.url)
    }

    if (authorize.method === "auto") {
      const result = await authorize.callback()
      if (result.type === "success") {
        await Auth.set(provider, {
          type: "oauth",
          access: result.access,
          refresh: result.refresh,
          expires: result.expires,
        })
      }
    }
  }

  return true
}
```

### MCP OAuth 状态管理

```typescript
export namespace McpAuth {
  // 存储 OAuth 令牌
  export async function updateTokens(mcpName: string, tokens: OAuthTokens): Promise<void> {
    const entry = await get(mcpName)
    entry.tokens = {
      accessToken: tokens.access_token,
      refreshToken: tokens.refresh_token,
      expiresAt: tokens.expires_at,
    }
    await set(mcpName, entry)
  }

  // 存储 PKCE code_verifier
  export async function updateCodeVerifier(mcpName: string, codeVerifier: string): Promise<void> {
    const entry = await get(mcpName)
    entry.codeVerifier = codeVerifier
    await set(mcpName, entry)
  }

  // 检查令牌是否过期
  export async function isTokenExpired(mcpName: string): Promise<boolean> {
    const entry = await get(mcpName)
    if (!entry.tokens) return true
    return entry.tokens.expiresAt < Date.now()
  }
}
```
