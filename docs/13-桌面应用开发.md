## 概述

OpenCode 桌面应用是基于 [Tauri](https://tauri.app) 构建的原生跨平台应用，它将 OpenCode 的 Web 界面封装在原生窗口中，同时提供桌面应用特有的功能，如：

- **原生文件选择器**：使用系统原生对话框选择文件和目录
- **本地存储**：使用 Tauri 的持久化存储系统
- **自动更新**：集成 Tauri 更新插件
- **系统通知**：原生桌面通知
- **系统菜单**：macOS 原生应用菜单
- **Sidecar 服务器**：自动启动和管理 OpenCode 服务器进程

### 设计原则

OpenCode 桌面应用遵循以下设计原则：

1. **代码复用**：前端代码与 Web 应用共享（`@opencode-ai/app`）
2. **轻量化**：使用 Tauri 的 WebView 而非 Electron，减少资源占用
3. **跨平台**：支持 macOS、Windows 和 Linux
4. **原生体验**：尽可能使用原生系统 API

### 架构说明

#### 前端 (TypeScript/SolidJS)

- **主入口** (`index.tsx`)：应用程序的主入口点，负责初始化平台提供者和等待服务器就绪
- **共享 UI**：复用 `@opencode-ai/app` 和 `@opencode-ai/ui` 包，与 Web 应用共享代码
- **平台抽象**：通过 `PlatformProvider` 提供统一的平台接口

#### 后端 (Rust)

- **主库** (`lib.rs`)：Tauri 应用的核心逻辑，包括服务器管理和命令处理
- **CLI 集成** (`cli.rs`)：管理与 OpenCode CLI sidecar 的交互
- **窗口自定义** (`window_customizer.rs`)：自定义窗口行为和样式

#### Tauri 插件

Tauri 使用插件系统扩展功能，OpenCode 使用了多个官方插件来访问原生 API。

#### Sidecar 服务器

桌面应用会自动启动和管理 OpenCode 服务器进程（sidecar），提供以下功能：

- 按需启动本地服务器
- 连接到自定义远程服务器
- 健康检查和自动重连
- 日志收集和监控

```typescript
function ServerGate(props: { children: (data: Accessor<ServerReadyData>) => JSX.Element }) {
  const [serverData] = createResource<ServerReadyData>(() =>
    invoke("ensure_server_ready").then((v) => {
      return new Promise((res) => setTimeout(() => res(v as ServerReadyData), 2000))
    })
  )

  return (
    <Show
      when={serverData.state !== "pending" && serverData()}
      fallback={
        <div class="h-screen w-screen flex flex-col items-center justify-center">
          <Splash class="w-16 h-20 opacity-50 animate-pulse" />
        </div>
      }
    >
      {(data) => props.children(data)}
    </Show>
  )
}
```

#### 自动更新

集成 `@tauri-apps/plugin-updater` 实现应用自动更新：

```typescript
import { check, Update } from "@tauri-apps/plugin-updater"

let update: Update | null = null

// 检查更新
const checkUpdate = async () => {
  const next = await check().catch(() => null)
  if (!next) return { updateAvailable: false }

  const ok = await next
    .download()
    .then(() => true)
    .catch(() => false)
  if (!ok) return { updateAvailable: false }

  update = next
  return { updateAvailable: true, version: next.version }
}

// 安装更新
const updateApp = async () => {
  if (!update) return
  await invoke("kill_sidecar") // 先停止 sidecar
  await update.install()
}
```

#### 通知

使用 `@tauri-apps/plugin-notification` 显示系统通知：

```typescript
import { isPermissionGranted, requestPermission } from "@tauri-apps/plugin-notification"

const notify = async (title, description, href) => {
  const granted = await isPermissionGranted().catch(() => false)
  const permission = granted ? "granted" : await requestPermission().catch(() => "denied")
  if (permission !== "granted") return

  const win = getCurrentWindow()
  const focused = await win.isFocused().catch(() => document.hasFocus())
  if (focused) return // 应用聚焦时不显示通知

  const notification = new Notification(title, {
    body: description ?? "",
    icon: "https://opencode.ai/favicon-96x96-v3.png",
  })

  notification.onclick = () => {
    win.show().catch(() => undefined)
    win.unminimize().catch(() => undefined)
    win.setFocus().catch(() => undefined)
    if (href) {
      window.history.pushState(null, "", href)
      window.dispatchEvent(new PopStateEvent("popstate"))
    }
    notification.close()
  }
}
```

### WebView 优化

#### 修复 `getComputedStyle` 问题

Floating UI 可能使用非元素调用 `getComputedStyle`，导致错误：

```typescript
const originalGetComputedStyle = window.getComputedStyle
window.getComputedStyle = ((elt: Element, pseudoElt?: string | null) => {
  if (!(elt instanceof Element)) {
    return originalGetComputedStyle(document.documentElement, pseudoElt ?? undefined)
  }
  return originalGetComputedStyle(elt, pseudoElt ?? undefined)
}) as typeof window.getComputedStyle
```

#### 禁用捏合缩放

在 WebView 中禁用 macOS 的捏合缩放手势：

```typescript
// src/webview-zoom.ts
export default function setupWebViewZoom() {
  if (typeof window === "undefined" || !("webkit" in window)) return

  const webkit = window as any

  webkit.messageHandlers.setZoomLevel?.postMessage(0)

  document.addEventListener(
    "wheel",
    (e) => {
      if (e.ctrlKey || e.metaKey) {
        e.preventDefault()
      }
    },
    { passive: false },
  )
}
```

```rust
pub fn run() {
    let updater_enabled = option_env!("TAURI_SIGNING_PRIVATE_KEY").is_some();

    let mut builder = tauri::Builder::default()
        .plugin(tauri_plugin_single_instance::init(|app, _args, _cwd| {
            // 单实例：聚焦现有窗口
            if let Some(window) = app.get_webview_window("main") {
                let _ = window.set_focus();
                let _ = window.unminimize();
            }
        }))
        .plugin(tauri_plugin_os::init())
        .plugin(tauri_plugin_window_state::Builder::new()
            .with_state_flags(
                tauri_plugin_window_state::StateFlags::all()
                    - tauri_plugin_window_state::StateFlags::DECORATIONS,
            )
            .build())
        .plugin(tauri_plugin_store::Builder::new().build())
        .plugin(tauri_plugin_dialog::init())
        .plugin(tauri_plugin_shell::init())
        .plugin(tauri_plugin_process::init())
        // ... 更多插件
        .invoke_handler(tauri::generate_handler![
            kill_sidecar,
            install_cli,
            ensure_server_ready,
            get_default_server_url,
            set_default_server_url
        ])
        .setup(move |app| {
            // 应用初始化
            Ok(())
        });

    builder
        .build(tauri::generate_context!())
        .expect("error while running tauri application")
        .run(|app, event| {
            if let RunEvent::Exit = event {
                kill_sidecar(app.clone());
            }
        });
}
```

#### 服务器连接管理

```rust
async fn setup_server_connection(
    app: &AppHandle,
    custom_url: Option<String>,
) -> Result<(Option<CommandChild>, ServerReadyData), String> {
    // 尝试连接自定义服务器
    if let Some(url) = custom_url {
        loop {
            if check_server_health(&url, None).await {
                println!("Connected to custom server: {}", url);
                return Ok((
                    None,
                    ServerReadyData {
                        url: url.clone(),
                        password: None,
                    },
                ));
            }

            let res = app.dialog()
              .message(format!("Could not connect to configured server:\n{}", url))
              .title("Connection Failed")
              .blocking_show_with_result();

            // 根据用户选择重试或启动本地服务器
            if matches!(res, MessageDialogResult::Custom(name) if name == RETRY) {
                continue;
            }
            break;
        }
    }

    // 启动本地服务器
    let local_port = get_sidecar_port();
    let local_url = format!("http://127.0.0.1:{local_port}");

    if !check_server_health(&local_url, None).await {
        let password = uuid::Uuid::new_v4().to_string();

        match spawn_local_server(app, local_port, &password).await {
            Ok(child) => Ok((
                Some(child),
                ServerReadyData {
                    url: local_url,
                    password: Some(password),
                },
            )),
            Err(err) => Err(err),
        }
    } else {
        Ok((
            None,
            ServerReadyData {
                url: local_url,
                password: None,
            },
        ))
    }
}
```

#### 健康检查

```rust
async fn check_server_health(url: &str, password: Option<&str>) -> bool {
    let Ok(url) = reqwest::Url::parse(url) else {
        return false;
    };

    let mut builder = reqwest::Client::builder().timeout(Duration::from_secs(3));

    if url_is_localhost(&url) {
        // 忽略本地服务器的代理设置
        builder = builder.no_proxy();
    };

    let Ok(client) = builder.build() else {
        return false;
    };

    let Ok(health_url) = url.join("/global/health") else {
        return false;
    };

    let mut req = client.get(health_url);

    if let Some(password) = password {
        req = req.basic_auth("opencode", Some(password));
    }

    req.send()
        .await
        .map(|r| r.status().is_success())
        .unwrap_or(false)
}
```

#### Sidecar 服务器启动

```rust
fn spawn_sidecar(app: &AppHandle, port: u32, password: &str) -> CommandChild {
    let log_state = app.state::<LogState>();
    let log_state_clone = log_state.inner().clone();

    println!("spawning sidecar on port {port}");

    let (mut rx, child) = cli::create_command(app, format!("serve --port {port}").as_str())
        .env("OPENCODE_SERVER_USERNAME", "opencode")
        .env("OPENCODE_SERVER_PASSWORD", password)
        .spawn()
        .expect("Failed to spawn opencode");

    // 异步收集日志
    tauri::async_runtime::spawn(async move {
        while let Some(event) = rx.recv().await {
            match event {
                CommandEvent::Stdout(line_bytes) => {
                    let line = String::from_utf8_lossy(&line_bytes);
                    print!("{line}");

                    // 存储日志
                    if let Ok(mut logs) = log_state_clone.0.lock() {
                        logs.push_back(format!("[STDOUT] {}", line));
                        while logs.len() > MAX_LOG_ENTRIES {
                            logs.pop_front();
                        }
                    }
                }
                CommandEvent::Stderr(line_bytes) => {
                    let line = String::from_utf8_lossy(&line_bytes);
                    eprint!("{line}");

                    if let Ok(mut logs) = log_state_clone.0.lock() {
                        logs.push_back(format!("[STDERR] {}", line));
                        while logs.len() > MAX_LOG_ENTRIES {
                            logs.pop_front();
                        }
                    }
                }
                _ => {}
            }
        }
    });

    child
}
```

#### CLI 安装

```rust
#[tauri::command]
pub fn install_cli(app: tauri::AppHandle) -> Result<String, String> {
    if cfg!(not(unix)) {
        return Err("CLI installation is only supported on macOS & Linux".to_string());
    }

    let sidecar = get_sidecar_path(&app);
    if !sidecar.exists() {
        return Err("Sidecar binary not found".to_string());
    }

    // 使用项目根目录的安装脚本
    let temp_script = std::env::temp_dir().join("opencode-install.sh");
    std::fs::write(&temp_script, INSTALL_SCRIPT)
        .map_err(|e| format!("Failed to write install script: {}", e))?;

    // 设置可执行权限
    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        std::fs::set_permissions(&temp_script, std::fs::Permissions::from_mode(0o755))
            .map_err(|e| format!("Failed to set script permissions: {}", e))?;
    }

    // 执行安装
    let output = std::process::Command::new(&temp_script)
        .arg("--binary")
        .arg(&sidecar)
        .output()
        .map_err(|e| format!("Failed to run install script: {}", e))?;

    let _ = std::fs::remove_file(&temp_script);

    if !output.status.success() {
        let stderr = String::from_utf8_lossy(&output.stderr);
        return Err(format!("Install script failed: {}", stderr));
    }

    let install_path = get_cli_install_path()
        .ok_or_else(|| "Could not determine install path".to_string())?;

    Ok(install_path.to_string_lossy().to_string())
}
```

#### CLI 同步

```rust
pub fn sync_cli(app: tauri::AppHandle) -> Result<(), String> {
    if cfg!(debug_assertions) {
        println!("Skipping CLI sync for debug build");
        return Ok(());
    }

    if !is_cli_installed() {
        println!("No CLI installation found, skipping sync");
        return Ok(());
    }

    let cli_path = get_cli_install_path()
        .ok_or_else(|| "Could not determine CLI install path".to_string())?;

    // 获取已安装 CLI 版本
    let output = std::process::Command::new(&cli_path)
        .arg("--version")
        .output()
        .map_err(|e| format!("Failed to get CLI version: {}", e))?;

    if !output.status.success() {
        return Err("Failed to get CLI version".to_string());
    }

    let cli_version_str = String::from_utf8_lossy(&output.stdout).trim().to_string();
    let cli_version = semver::Version::parse(&cli_version_str)
        .map_err(|e| format!("Failed to parse CLI version '{}': {}", cli_version_str, e))?;

    let app_version = app.package_info().version.clone();

    // 如果 CLI 版本 >= 应用版本，无需同步
    if cli_version >= app_version {
        println!(
            "CLI version {} is up to date (app version: {}), skipping sync",
            cli_version, app_version
        );
        return Ok(());
    }

    println!(
        "CLI version {} is older than app version {}, syncing",
        cli_version, app_version
    );

    install_cli(app)?;

    println!("Synced installed CLI");

    Ok(())
}
```

```rust
pub fn create_command(app: &AppHandle, args: &str) -> Command {
    let state_dir = app
        .path()
        .resolve("", BaseDirectory::AppLocalData)
        .expect("Failed to resolve app local data dir");

    #[cfg(target_os = "windows")]
    return app
        .shell()
        .sidecar("opencode-cli")
        .unwrap()
        .args(args.split_whitespace())
        .env("OPENCODE_EXPERIMENTAL_ICON_DISCOVERY", "true")
        .env("OPENCODE_CLIENT", "desktop")
        .env("XDG_STATE_HOME", &state_dir);

    #[cfg(not(target_os = "windows"))]
    {
        let sidecar = get_sidecar_path(app);
        let shell = get_user_shell();

        let cmd = if shell.ends_with("/nu") {
            format!("^\"{}\" {}", sidecar.display(), args)
        } else {
            format!("\"{}\" {}", sidecar.display(), args)
        };

        app.shell()
            .command(&shell)
            .env("OPENCODE_EXPERIMENTAL_ICON_DISCOVERY", "true")
            .env("OPENCODE_CLIENT", "desktop")
            .env("XDG_STATE_HOME", &state_dir)
            .args(["-il", "-c", &cmd])
    }
}
```

```rust
#[cfg(target_os = "linux")]
fn configure_display_backend() -> Option<String> {
    use std::env;

    let on_wayland = env::var_os("WAYLAND_DISPLAY").is_some()
        || matches!(
            env::var("XDG_SESSION_TYPE"),
            Ok(v) if v.eq_ignore_ascii_case("wayland")
        );
    if !on_wayland {
        return None;
    }

    // 优先使用 X11 避免 Wayland 协议错误
    if env::var_os("DISPLAY").is_some() {
        unsafe { env::set_var("WINIT_UNIX_BACKEND", "x11") };
        unsafe { env::set_var("GDK_BACKEND", "x11") };
        unsafe { env::set_var("WEBKIT_DISABLE_DMABUF_RENDERER", "1") };
        return Some("Forced X11 backend".into());
    }

    Some("Wayland enabled".into())
}
```

```rust
fn setup_tray(app: &AppHandle) -> tauri::Result<()> {
    let tray = tauri::tray::TrayIconBuilder::new()
        .icon(app.default_window_icon().unwrap().clone())
        .menu(
            &tauri::menu::MenuBuilder::new(app)
                .item("show", "Show")
                .item("quit", "Quit")
                .build()?
        )
        .on_menu_event(|app, event| {
            match event.id.as_ref() {
                "show" => {
                    if let Some(window) = app.get_webview_window("main") {
                        let _ = window.show();
                        let _ = window.set_focus();
                    }
                }
                "quit" => {
                    app.exit(0);
                }
                _ => {}
            }
        })
        .build(app)?;

    Ok(())
}
```

## 故障排除

### 常见错误

#### 1. `Error: Failed to spawn sidecar`

**原因**：sidecar 二进制未找到或无法执行

**解决方案**：

- 检查 `sidecars/opencode-cli` 是否存在
- 检查文件权限（Linux/macOS 需要执行权限）
- 重新构建应用

#### 2. `Error: Connection refused`

**原因**：无法连接到服务器

**解决方案**：

- 检查服务器是否正在运行
- 检查端口号是否正确
- 检查防火墙设置

#### 3. `Error: Plugin not found`

**原因**：Tauri 插件未正确注册

**解决方案**：

- 检查 `Cargo.toml` 中是否添加了依赖
- 检查 `.plugin()` 是否正确调用
- 重新构建

#### 4. macOS 应用无法启动

**原因**：Gatekeeper 阻止应用运行

**解决方案**：

```bash
# 移除隔离属性
xattr -cr /Applications/OpenCode.app

# 或右键点击应用，选择"打开"
```

### 性能问题

#### 1. 应用启动慢

**优化建议**：

- 延迟加载非关键资源
- 优化 bundle 大小
- 使用代码分割

#### 2. WebView 渲染慢

**优化建议**：

- 减少不必要的 DOM 操作
- 使用虚拟列表
- 优化 CSS 选择器

### 平台特定问题

#### macOS

- **问题**：标题栏按钮位置不正确
  - 调整 `trafficLightPosition` 配置

- **问题**：通知权限被拒绝
  - 引导用户在系统设置中授权

#### Windows

- **问题**：无边框窗口显示异常
  - 检查 DWM 缩放设置
  - 检查窗口状态管理

#### Linux

- **问题**：Wayland 显示问题
  - 使用 X11 后端
  - 设置 `OC_ALLOW_WAYLAND=1` 强制使用 Wayland
