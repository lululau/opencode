## 安装问题

### 1.1 安装脚本失败

**症状：**

```bash
$ curl -fsSL https://opencode.ai/install | bash
# 无响应或报错
curl: (7) Failed to connect to opencode.ai port 443
```

**诊断步骤：**

1. **检查网络连接：**

   ```bash
   # 测试连接
   curl -I https://opencode.ai/install

   # 检查 DNS 解析
   nslookup opencode.ai
   ```

2. **检查代理设置：**

   ```bash
   echo $HTTP_PROXY
   echo $HTTPS_PROXY

   # 如果使用代理，需要配置
   export HTTPS_PROXY=http://proxy.example.com:8080
   ```

3. **尝试备用安装方式：**

   ```bash
   # 使用 npm
   npm i -g opencode-ai@latest

   # 使用 bun
   bun add -g opencode-ai@latest

   # 手动下载二进制文件
   # 访问 https://github.com/anomalyco/opencode/releases
   ```

**解决方案：**

- ✅ 检查网络连接和 DNS
- ✅ 配置代理或使用 VPN
- ✅ 使用包管理器安装（npm/bun/yarn）
- ✅ 手动下载预编译二进制文件

### 1.2 权限错误

**症状：**

```bash
$ opencode
Error: EACCES: permission denied, mkdir '/usr/local/bin/opencode'
```

**诊断步骤：**

1. **检查目标目录权限：**

   ```bash
   ls -la /usr/local/bin/
   ```

2. **检查当前用户：**
   ```bash
   whoami
   ```

**解决方案：**

```bash
# 方案 1：使用 sudo（不推荐）
sudo curl -fsSL https://opencode.ai/install | bash

# 方案 2：安装到用户目录（推荐）
export OPENCODE_INSTALL_DIR=$HOME/.local/bin
curl -fsSL https://opencode.ai/install | bash

# 方案 3：使用 XDG 目录
export XDG_BIN_DIR=$HOME/.local/bin
curl -fsSL https://opencode.ai/install | bash

# 确保目录在 PATH 中
export PATH=$HOME/.local/bin:$PATH
```

### 1.3 版本升级失败

**症状：**

```bash
$ curl -fsSL https://opencode.ai/install | bash
# 版本没有更新
$ opencode --version
0.1.5  # 应该是 0.1.6
```

**诊断步骤：**

1. **检查安装目录：**

   ```bash
   which opencode
   ```

2. **检查多个版本：**
   ```bash
   ls -la /usr/local/bin/opencode*
   ls -la ~/.local/bin/opencode*
   ```

**解决方案：**

```bash
# 1. 卸载旧版本
opencode uninstall

# 或手动删除
rm -rf /usr/local/bin/opencode
rm -rf ~/.opencode

# 2. 清理缓存
rm -rf ~/.local/share/opencode

# 3. 重新安装
curl -fsSL https://opencode.ai/install | bash
```

### 1.4 依赖问题

**症状：**

```bash
$ bun install
error: Bun is not installed
```

**诊断步骤：**

```bash
# 检查 Bun 版本
bun --version

# 检查 PATH
which bun

# 检查 Bun 安装
ls -la ~/.bun/bin/bun
```

**解决方案：**

```bash
# 安装 Bun
curl -fsSL https://bun.sh/install | bash

# 设置 PATH
export PATH="$HOME/.bun/bin:$PATH"

# 验证安装
bun --version
```

**从源码开发：**

```bash
# 1. 克隆仓库
git clone https://github.com/anomalyco/opencode.git
cd opencode

# 2. 安装依赖
bun install

# 3. 运行
bun dev
```

## 配置问题

### 2.1 配置文件找不到

**症状：**

```
Error: Config file not found: ~/.opencode/config.json
```

**诊断步骤：**

```bash
# 检查配置目录
ls -la ~/.opencode/

# 检查其他可能的位置
ls -la ~/.config/opencode/
ls -la ~/Library/Application\ Support/opencode/
```

**解决方案：**

```bash
# 1. 创建配置目录
mkdir -p ~/.opencode

# 2. 创建最小配置
cat > ~/.opencode/config.json << 'EOF'
{
  "providers": {}
}
EOF

# 3. 验证配置
opencode config check
```

**配置文件位置：**

- Linux/macOS: `~/.opencode/config.json`
- Windows: `%APPDATA%\opencode\config.json`

### 2.2 配置格式错误

**症状：**

```
Error: Config.JsonError
Invalid JSON in config file: Unexpected token
```

**诊断步骤：**

```bash
# 验证 JSON 格式
cat ~/.opencode/config.json | jq .

# 或使用 Python
python -m json.tool ~/.opencode/config.json
```

**解决方案：**

```json
// 正确的配置文件示例
{
  "default_agent": "build",
  "providers": {
    "anthropic": {
      "api_key": "your-api-key-here"
    }
  },
  "models": {
    "default": "anthropic/claude-3-5-sonnet-20241022"
  }
}
```

**常见错误：**

- ❌ 缺少逗号 `}` vs `},`
- ❌ 末尾逗号（标准 JSON 不允许）
- ❌ 单引号 `'key'` vs `"key"`
- ❌ 注释 `// comment`（标准 JSON 不支持）

### 2.3 API Key 配置问题

**症状：**

```
Error: Provider.AuthError
Failed to load API key for provider 'anthropic'
```

**诊断步骤：**

1. **检查环境变量：**

   ```bash
   echo $ANTHROPIC_API_KEY
   echo $OPENAI_API_KEY
   ```

2. **检查配置文件：**
   ```bash
   cat ~/.opencode/config.json | grep api_key
   ```

**解决方案：**

**方案 1：环境变量（推荐）：**

```bash
# Bash/Zsh
echo 'export ANTHROPIC_API_KEY="your-key-here"' >> ~/.bashrc
source ~/.bashrc

# Fish
set -gx ANTHROPIC_API_KEY "your-key-here"
```

**方案 2：配置文件：**

```json
{
  "providers": {
    "anthropic": {
      "api_key": "your-key-here"
    }
  }
}
```

**方案 3：交互式配置：**

```bash
opencode auth add
# 按提示输入 provider 和 API key
```

### 2.4 模型配置错误

**症状：**

```
Error: Provider.ModelNotFoundError
Model not found: openai/gpt-5

Try: opencode models
```

**诊断步骤：**

```bash
# 列出可用模型
opencode models

# 检查配置的模型
opencode config get models.default
```

**解决方案：**

```bash
# 1. 查看可用模型
opencode models

# 2. 选择并设置默认模型
opencode config set models.default "anthropic/claude-3-5-sonnet-20241022"

# 3. 验证
opencode config get models.default
```

**有效模型格式：**

- ✅ `anthropic/claude-3-5-sonnet-20241022`
- ✅ `openai/gpt-4-turbo`
- ✅ `google/gemini-pro`
- ❌ `claude-3-5` (缺少 provider 前缀)
- ❌ `gpt-4` (缺少 provider 前缀)

## 运行时错误

### 3.1 启动失败

**症状：**

```bash
$ opencode
Error: Failed to start server on port 4096
Address already in use
```

**诊断步骤：**

```bash
# 1. 检查端口占用
lsof -i :4096

# Linux/Windows
netstat -tulpn | grep 4096

# 2. 检查运行中的进程
ps aux | grep opencode
```

**解决方案：**

```bash
# 方案 1：杀死占用端口的进程
lsof -ti:4096 | xargs kill -9

# 方案 2：使用不同端口
opencode serve --port 4097

# 方案 3：附加到现有会话
opencode attach
```

### 3.2 工作目录问题

**症状：**

```
Error: Not a git repository
Worktrees are only supported for git projects
```

**诊断步骤：**

```bash
# 检查是否为 git 仓库
git status

# 检查 .git 目录
ls -la .git

# 初始化 git（如果需要）
git init
```

**解决方案：**

```bash
# 1. 初始化 git（如果项目还不是仓库）
git init
git add .
git commit -m "Initial commit"

# 2. 或在非 git 目录中运行
cd ~/my-project
opencode
```

### 3.3 LSP 初始化失败

**症状：**

```
Error: LSP.InitializeError
Failed to initialize LSP server for TypeScript
```

**诊断步骤：**

```bash
# 1. 检查语言服务器
which tsserver
which typescript-language-server

# 2. 检查文件类型
file test.ts

# 3. 查看 LSP 日志
tail -f ~/.local/share/opencode/logs/dev.log | grep lsp
```

**解决方案：**

```bash
# 1. 安装语言服务器
npm install -g typescript typescript-language-server

# 2. 配置 LSP
opencode config set lsp.typescript.command "typescript-language-server"

# 3. 重启 OpenCode
opencode
```

### 3.4 权限被拒绝

**症状：**

```
Error: Permission.DeniedError
Permission denied: bash command 'rm -rf /'
```

**诊断步骤：**

```bash
# 1. 检查权限规则
opencode agent config build
opencode config get permission

# 2. 查看权限历史
opencode session list
```

**解决方案：**

**方案 1：配置权限规则：**

```json
{
  "permission": [
    {
      "action": "allow",
      "permission": "bash",
      "patterns": ["npm install", "git status"]
    },
    {
      "action": "deny",
      "permission": "bash",
      "patterns": ["rm -rf /", "sudo"]
    }
  ]
}
```

**方案 2：切换到有权限的代理：**

```bash
# 使用 build 代理（完全访问）
opencode agent switch build

# 使用 plan 代理（只读，更安全）
opencode agent switch plan
```

### 3.5 网络连接错误

**症状：**

```
Error: ECONNRESET
Connection reset by peer
```

**诊断步骤：**

```bash
# 1. 测试网络连接
curl -I https://api.anthropic.com

# 2. 检查代理设置
env | grep -i proxy

# 3. 检查防火墙
# Windows
netsh advfirewall show allprofiles

# macOS
sudo pfctl -s rules
```

**解决方案：**

```bash
# 1. 配置代理
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=http://proxy.example.com:8080

# 2. 增加超时时间
opencode config set provider.timeout 60000

# 3. 使用网络调试工具
curl -v https://api.anthropic.com/v1/messages
```

## 性能问题

### 4.1 响应速度慢

**症状：**

- AI 响应时间长（>10 秒）
- 工具执行缓慢
- 界面卡顿

**诊断步骤：**

```bash
# 1. 测试网络延迟
ping api.anthropic.com

# 2. 检查 CPU 使用率
top | grep opencode

# 3. 查看性能日志
grep "duration=" ~/.local/share/opencode/logs/dev.log
```

**解决方案：**

**网络优化：**

```bash
# 1. 选择更近的模型
opencode config set models.default "anthropic/claude-3-haiku-20240307"

# 2. 减少上下文窗口
opencode config set agent.max_tokens 4096

# 3. 使用流式响应（默认已启用）
opencode config set agent.stream true
```

**本地优化：**

```bash
# 1. 使用更快的模型（Haiku vs Sonnet）
opencode config set models.default "anthropic/claude-3-haiku-20240307"

# 2. 减少并发请求
opencode config set agent.parallel_tools 1

# 3. 清理缓存
rm -rf ~/.local/share/opencode/cache/*
```

### 4.2 内存占用高

**症状：**

- OpenCode 使用大量内存（>1GB）
- 系统变慢
- 内存泄漏

**诊断步骤：**

```bash
# 1. 检查内存使用
ps aux | grep opencode

# 2. 监控内存增长
watch -n 1 'ps aux | grep opencode'

# 3. 查看日志中的内存信息
grep "Memory usage" ~/.local/share/opencode/logs/dev.log
```

**解决方案：**

```bash
# 1. 限制上下文大小
opencode config set agent.max_input_tokens 100000

# 2. 启用会话压缩
opencode config set session.compaction.enabled true

# 3. 定期清理旧会话
opencode session cleanup --older-than 7d

# 4. 减少并发工具执行
opencode config set agent.parallel_tools 1
```

### 4.3 磁盘 I/O 缓慢

**症状：**

- 文件读写慢
- 大型项目加载慢
- 索引更新慢

**诊断步骤：**

```bash
# 1. 检查磁盘 I/O
iostat -x 1

# 2. 检查磁盘空间
df -h ~/.local/share/opencode

# 3. 查找大文件
du -sh ~/.local/share/opencode/* | sort -hr
```

**解决方案：**

```bash
# 1. 清理旧日志
find ~/.local/share/opencode/logs -name "*.log" -mtime +30 -delete

# 2. 清理缓存
opencode cache clear

# 3. 使用更快的存储
# 将项目移动到 SSD 而不是 HDD
```

### 4.4 渲染性能问题（TUI/Web）

**症状：**

- 终端滚动慢
- Web 界面卡顿
- 大文件显示慢

**诊断步骤：**

**TUI：**

```bash
# 1. 测试终端性能
opencode --debug

# 2. 检查终端类型
echo $TERM

# 3. 使用更快的终端
# 推荐使用 kitty, wezterm, alacritty
```

**Web：**

```bash
# 1. 打开浏览器 DevTools
# Performance 标签页
# 录制页面加载

# 2. 查看网络请求
# Network 标签页
# 检查慢请求

# 3. 查看控制台
# Console 标签页
# 检查错误和警告
```

**解决方案：**

```bash
# TUI 优化
opencode config set tui.render_mode "fast"
opencode config set tui.max_lines 1000

# Web 优化
# 使用现代浏览器（Chrome, Firefox, Edge）
# 禁用扩展
# 使用硬件加速
```

## 兼容性问题

### 5.1 操作系统兼容性

**支持的操作系统：**

- ✅ macOS 12+ (Apple Silicon, Intel)
- ✅ Linux (Ubuntu, Debian, Arch, etc.)
- ✅ Windows 10/11

**不支持的操作系统：**

- ❌ macOS < 12
- ❌ Windows < 10
- ❌ Windows 7/8

### 5.2 Node.js 版本问题

**症状：**

```
Error: Unsupported Node.js version: 16.x
Minimum required: 18.x
```

**诊断步骤：**

```bash
# 检查 Node.js 版本
node --version

# 检查 Bun 版本
bun --version
```

**解决方案：**

```bash
# 使用 Bun（推荐，无需 Node.js）
curl -fsSL https://bun.sh/install | bash

# 或升级 Node.js
# 使用 nvm
nvm install 20
nvm use 20

# 或使用 n
sudo n latest
```

### 5.3 终端兼容性

**支持的终端：**

- ✅ iTerm2
- ✅ Terminal.app
- ✅ GNOME Terminal
- ✅ Windows Terminal
- ✅ kitty
- ✅ alacritty
- ✅ wezterm

**已知问题：**

**旧终端：**

```
终端：xterm, rxvt, urxvt
问题：不支持真彩色
解决：opencode config set tui.colors false
```

**Windows CMD：**

```
问题：不支持 ANSI 转义序列
解决：使用 PowerShell 或 Windows Terminal
```

### 5.4 编码问题

**症状：**

```
Error: Invalid UTF-8 encoding
Failed to read file: filename.txt
```

**诊断步骤：**

```bash
# 检查文件编码
file -i filename.txt

# 检查终端编码
echo $LANG
locale charmap
```

**解决方案：**

```bash
# 1. 设置正确的 locale
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8

# 2. 转换文件编码
iconv -f ISO-8859-1 -t UTF-8 filename.txt > filename-utf8.txt

# 3. 使用 UTF-8 编码的编辑器
# VSCode, Vim, Emacs 默认使用 UTF-8
```

### 5.5 Git 版本兼容性

**症状：**

```
Error: Worktree command failed
git worktree: unsupported option
```

**诊断步骤：**

```bash
# 检查 Git 版本
git --version
```

**解决方案：**

```bash
# 升级 Git
# macOS
brew upgrade git

# Ubuntu/Debian
sudo apt update && sudo apt install git

# Arch
sudo pacman -S git

# Windows
# 下载最新版：https://git-scm.com/download/win
```

**最低要求：**

- Git >= 2.17（worktree 支持）

## 解决方案

### 7.1 常见快速修复

| 问题         | 快速修复                                              |
| ------------ | ----------------------------------------------------- |
| 安装失败     | 使用 `npm i -g opencode-ai`                           |
| 配置错误     | 运行 `opencode config check`                          |
| API Key 失败 | 使用 `opencode auth add`                              |
| 端口占用     | `lsof -ti:4096 \| xargs kill`                         |
| 内存占用高   | `opencode config set session.compaction.enabled true` |
| 响应慢       | 切换到 Haiku 模型                                     |
| LSP 失败     | 安装 `typescript-language-server`                     |
| 权限错误     | 切换到 `build` 代理                                   |
| 网络错误     | 配置 `HTTP_PROXY`                                     |

### 7.2 重置和恢复

```bash
# 1. 重置配置
rm -f ~/.opencode/config.json

# 2. 清除缓存
rm -rf ~/.local/share/opencode/cache/*

# 3. 删除会话
opencode session clear --all

# 4. 重新开始
opencode
```
