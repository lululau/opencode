## 概述

OpenCode 使用 TypeScript 构建了一个强类型系统。本文档列出了所有核心类型定义、接口、枚举及其在代码库中的位置。

**类型系统特点**:

- **严格类型**: 使用 TypeScript 的严格模式
- **Zod 验证**: 所有输入使用 Zod schema 验证
- **OpenAPI 规范**: API 类型从 OpenAPI 规范自动生成
- **命名约定**:
  - 接口: PascalCase (如 `AgentInfo`, `ToolContext`)
  - 类型别名: PascalCase (如 `SessionStatus`, `PermissionAction`)
  - 变量: camelCase (如 `sessionID`, `permission`)
  - 常量: UPPER_SNAKE_CASE (如 `OPENCODE_CONFIG_DIR`)

## 核心类型

### Plugin 系统类型

**位置**: `packages/plugin/src/index.ts`

#### Hooks 接口

插件生命周期钩子，用于扩展 OpenCode 功能。

```typescript
interface Hooks {
  // 事件钩子
  event?: (event: Event) => void | Promise<void>

  // 配置钩子
  config?: (config: Config) => Config | Promise<Config>

  // 工具钩子
  tool?: (tools: Tool.Info[]) => Tool.Info[] | Promise<Tool.Info[]>

  // 认证钩子
  auth?: (context: ProviderContext) => AuthHook | Promise<AuthHook>

  // 聊天钩子
  chat?: {
    message?: (message: Message) => Message | Promise<Message>
    params?: (params: Record<string, any>) => Record<string, any>
    headers?: (headers: Headers) => Headers | Promise<Headers>
  }

  // 权限钩子
  permission?: {
    ask?: (request: PermissionRequest) => PermissionResponse | Promise<PermissionResponse>
  }

  // 命令钩子
  command?: {
    execute?: {
      before?: (context: CommandContext) => void | Promise<void>
      after?: (context: CommandContext, result: CommandResult) => void | Promise<void>
    }
  }

  // 工具执行钩子
  tool?: {
    execute?: {
      before?: (context: ToolContext) => void | Promise<void>
      after?: (context: ToolContext, result: ToolResult) => void | Promise<void>
    }
  }

  // 实验性钩子
  experimental?: {
    [key: string]: any
  }
}
```
