## 概述

会话管理是 OpenCode 的核心子系统之一,负责管理用户与 AI 代理之间的完整交互历史。它不仅存储消息,还跟踪会话状态、管理事件流、处理消息压缩、维护父子会话关系,并提供会话持久化和检索功能。

### 核心职责

- **会话生命周期管理**：创建、更新、删除会话
- **消息存储和检索**：持久化所有用户和代理消息
- **事件流处理**：实时处理和广播会话事件
- **状态管理**：跟踪会话的执行状态（空闲、忙碌、重试）
- **消息压缩**：自动压缩长会话以控制上下文大小
- **会话摘要**：自动生成会话标题和摘要
- **父子关系**：支持会话分支和派生
- **会话分享**：生成和管理会话分享链接

## 会话数据结构

### Session.Info

会话元数据的核心类型定义：

```typescript
export interface Session.Info {
  id: string                    // 唯一会话 ID（ULID 格式）
  slug: string                  // URL 友好的标识符
  projectID: string            // 所属项目 ID
  directory: string             // 工作目录
  parentID?: string            // 父会话 ID（用于派生会话）
  summary?: {
    additions: number          // 添加的行数
    deletions: number          // 删除的行数
    files: number             // 修改的文件数
    diffs?: FileDiff[]        // 文件差异列表
  }
  share?: {
    url: string               // 分享 URL
  }
  title: string                // 会话标题
  version: string             // OpenCode 版本
  time: {
    created: number           // 创建时间戳
    updated: number           // 更新时间戳
    compacting?: number      // 压缩时间戳
    archived?: number        // 归档时间戳
  }
  permission?: Ruleset          // 权限规则
  revert?: {
    messageID: string        // 回滚目标消息 ID
    partID?: string         // 回滚目标部分 ID
    snapshot?: string        // 文件系统快照
    diff?: string           // 差异内容
  }
}
```

### 会话 ID 生成

OpenCode 使用 **ULID（Universally Unique Lexicographically Sortable Identifier）**作为会话 ID：

```typescript
import { Identifier } from "@/id/id"

// 降序 ID（默认，新的在前）
const sessionID = Identifier.descending("session")

// 升序 ID（旧的在前）
const sessionID = Identifier.ascending("message")
```

ULID 的优势：

- 按时间排序（新会话有更大的 ID）
- 全局唯一
- URL 友好（类似 UUID 但更短）
- 适合数据库索引

## 会话生命周期

### 1. 创建会话

```typescript
import { Session } from "@/session"

// 创建新会话
const session = await Session.create({
  title: "新功能开发", // 可选,默认自动生成
  parentID: "parent_session_id", // 可选,创建子会话
  permission: {
    // 可选,权限规则
    bash: "ask",
    edit: "allow",
  },
})
```

**内部实现**：

```typescript
export async function createNext(input: {
  id?: string
  title?: string
  parentID?: string
  directory: string
  permission?: Ruleset
}) {
  const result: Info = {
    id: Identifier.descending("session", input.id),
    slug: Slug.create(), // 生成 URL 友好标识符
    version: Installation.VERSION,
    projectID: Instance.project.id,
    directory: input.directory,
    parentID: input.parentID,
    title: input.title ?? createDefaultTitle(!!input.parentID),
    permission: input.permission,
    time: {
      created: Date.now(),
      updated: Date.now(),
    },
  }

  // 持久化到存储
  await Storage.write(["session", Instance.project.id, result.id], result)

  // 发布事件
  Bus.publish(Event.Created, { info: result })

  // 自动分享（如果配置启用）
  if (!result.parentID && (Flag.OPENCODE_AUTO_SHARE || cfg.share === "auto")) share(result.id)

  return result
}
```

### 3. 会话循环

`SessionPrompt.loop` 是会话的核心处理循环：

```typescript
export const loop = fn(Identifier.schema("session"), async (sessionID) => {
  const abort = start(sessionID)        // 启动会话,获取 AbortSignal

  while (true) {
    SessionStatus.set(sessionID, { type: "busy" })

    // 1. 获取过滤后的消息（排除已压缩的消息）
    let msgs = await MessageV2.filterCompacted(
      MessageV2.stream(sessionID)
    )

    // 2. 检查最后一个用户和助手消息
    let lastUser = msgs.findLast(m => m.info.role === "user")
    let lastAssistant = msgs.findLast(m => m.info.role === "assistant")

    // 3. 检查是否需要退出循环
    if (lastAssistant?.finish &&
        !["tool-calls", "unknown"].includes(lastAssistant.finish) &&
        lastUser.id < lastAssistant.id) {
      break  // 正常完成
    }

    // 4. 处理待处理的子任务
    const task = tasks.pop()
    if (task?.type === "subtask") {
      // 执行子任务（如 explore、general 代理）
      continue
    }

    // 5. 检查是否需要压缩
    if (await SessionCompaction.isOverflow({ tokens, model })) {
      await SessionCompaction.create({ ... })
      continue
    }

    // 6. 正常处理（调用 LLM）
    const processor = SessionProcessor.create({ ... })
    const result = await processor.process({ ... })

    if (result === "stop") break
    if (result === "compact") {
      await SessionCompaction.create({ ... })
    }
  }

  return lastMessage
})
```

**循环状态图**：

```
开始
  ↓
检查最后一条用户消息
  ↓
检查最后一条助手消息
  ↓
检查是否有未完成的子任务?
  ├─ 是 → 执行子任务 → 继续循环
  └─ 否 ↓
检查是否需要压缩?
  ├─ 是 → 执行压缩 → 继续循环
  └─ 否 ↓
处理助手响应（LLM）
  ↓
检查完成原因
  ├─ tool-calls/unknown → 继续循环
  ├─ stop → 退出循环
  └─ compact → 执行压缩 → 继续循环
```

### 4. 删除会话

```typescript
await Session.remove("session_id")
```

**删除流程**：

1. 递归删除所有子会话
2. 移除会话分享
3. 删除所有消息和部分
4. 从存储中删除会话
5. 发布 `session.deleted` 事件

## 消息系统

### 消息类型

OpenCode 使用 `MessageV2` 命名空间,支持多种消息类型：

```typescript
export type Message = User | Assistant

  id: string
  sessionID: string
  role: "user"
  time: { created: number }
  agent: string                    // 使用的代理
  model: {
    providerID: string
    modelID: string
  }
  system?: string                  // 自定义系统提示词
  tools?: Record<string, boolean>   // 可用工具
  variant?: string                 # 模型变体
  summary?: {
    title?: string
    body?: string
    diffs?: FileDiff[]
  }
}

// 助手消息
export interface Assistant {
  id: string
  sessionID: string
  role: "assistant"
  time: {
    created: number
    completed?: number
  }
  parentID: string                # 父消息 ID（通常是用户消息）
  modelID: string
  providerID: string
  mode: string                   # @deprecated
  agent: string
  path: {
    cwd: string                 # 当前工作目录
    root: string                # 项目根目录
  }
  summary?: boolean              # 是否为压缩消息
  cost: number                  # 本次响应成本
  tokens: {
    input: number              # 输入 tokens
    output: number             # 输出 tokens
    reasoning: number          # 推理 tokens
    cache: {
      read: number           # 缓存读取 tokens
```

### 消息部分（Parts）

每条消息包含多个部分（Parts）,支持不同类型的内容：

```typescript
export type Part =

export interface ReasoningPart {
```

## 会话状态管理

### 状态类型

会话有三种状态：

```typescript
export type SessionStatus =
  | { type: "idle" }           # 空闲
  | { type: "busy" }           # 忙碌（正在处理）
  | { type: "retry"            # 重试
      attempt: number
      message: string
      next: number             # 下次重试时间
    }
```

### 状态管理 API

```typescript
import { SessionStatus } from "@/session/status"

// 获取状态
const status = SessionStatus.get("session_id")
console.log(status) // { type: "idle" } 或其他状态

// 列出所有状态
const allStatus = SessionStatus.list()

// 设置状态
SessionStatus.set("session_id", { type: "busy" })

// 忙碌检查
function assertNotBusy(sessionID: string) {
  const status = SessionStatus.get(sessionID)
  if (status.type !== "idle") throw new Session.BusyError(sessionID)
}
```

### 状态转换

```
空闲 (idle)
  ↓
开始处理
  ↓
忙碌 (busy)
  ↓
  ├─ 处理完成 → 空闲 (idle)
  ├─ 遇到错误,可重试 → 重试 (retry)
  │                    ↓
  │                 重试成功 → 忙碌 (busy)
  │                 重试失败 → 空闲 (idle)
  └─ 用户取消 → 空闲 (idle)
```

### 状态事件

```typescript
SessionStatus.Event = {
  Status: BusEvent.define(
    "session.status",
    z.object({
      sessionID: z.string(),
      status: SessionStatus.Info
    })
  ),
  Idle: BusEvent.define(  # @deprecated
    "session.idle",
    z.object({
      sessionID: z.string()
    })
  )
}

// 订阅状态变化
Bus.subscribe(SessionStatus.Event.Status, (event) => {
  console.log(`会话 ${event.sessionID} 状态:`, event.status.type)

  if (event.status.type === "retry") {
    console.log(`重试 ${event.status.attempt} 次,下次:`, new Date(event.status.next))
  }
})
```

### 会话分支（Fork）

`Session.fork` 用于在特定消息点创建新分支：

```typescript
const forked = await Session.fork({
  sessionID: "original_session_id",
  messageID: "message_id_to_fork_from", // 可选,默认所有消息
})
```

**实现逻辑**：

```typescript
export const fork = async (input) => {
  // 1. 创建新会话
  const session = await createNext({ directory: Instance.directory })

  // 2. 获取原始消息
  const msgs = await messages({ sessionID: input.sessionID })

  // 3. 复制消息（建立 ID 映射）
  const idMap = new Map<string, string>()
  for (const msg of msgs) {
    // 停止在指定消息 ID
    if (input.messageID && msg.info.id >= input.messageID) break

    // 生成新 ID
    const newID = Identifier.ascending("message")
    idMap.set(msg.info.id, newID)

    // 复制消息
    const cloned = await updateMessage({
      ...msg.info,
      sessionID: session.id,
      id: newID,
      parentID: msg.info.role === "assistant" && msg.info.parentID ? idMap.get(msg.info.parentID) : undefined,
    })

    // 复制所有部分
    for (const part of msg.parts) {
      await updatePart({
        ...part,
        id: Identifier.ascending("part"),
        messageID: cloned.id,
        sessionID: session.id,
      })
    }
  }

  return session
}
```

### 压缩触发条件

```typescript
export async function isOverflow(input: { tokens: MessageV2.Assistant["tokens"]; model: Provider.Model }) {
  const config = await Config.get()
  if (config.compaction?.auto === false) return false

  const context = input.model.limit.context
  if (context === 0) return false

  // 计算 tokens 总数
  const count = input.tokens.input + input.tokens.cache.read + input.tokens.output

  const output = Math.min(input.model.limit.output, SessionPrompt.OUTPUT_TOKEN_MAX) || SessionPrompt.OUTPUT_TOKEN_MAX

  // 可用 tokens = 上下文 - 输出预算
  const usable = input.model.limit.input || context - output

  // 超过阈值则触发压缩
  return count > usable
}
```

### 消息修剪（Pruning）

修剪机制定期清理旧工具输出以节省空间：

```typescript
export async function prune(input: { sessionID: string }) {
  const msgs = await Session.messages({ sessionID: input.sessionID })
  let total = 0
  const toPrune = []

  // 向后遍历,找到 40K tokens 的工具调用
  // 然后擦除之前工具调用的输出
  for (let i = msgs.length - 1; i >= 0; i--) {
    const msg = msgs[i]
    for (let j = msg.parts.length - 1; j >= 0; j--) {
      const part = msg.parts[j]
      if (part.type === "tool" && part.state.status === "completed") {
        // 跳过受保护的工具（如 skill）
        if (PRUNE_PROTECTED_TOOLS.includes(part.tool)) continue

        // 如果已经被压缩则停止
        if (part.state.time.compacted) break

        // 估计 tokens
        const estimate = Token.estimate(part.state.output)
        total += estimate

        // 超过保护阈值则加入修剪列表
        if (total > PRUNE_PROTECT) {
          pruned += estimate
          toPrune.push(part)
        }
      }
    }
  }

  // 标记为已压缩
  if (pruned > PRUNE_MINIMUM) {
    for (const part of toPrune) {
      part.state.time.compacted = Date.now()
      await Session.updatePart(part)
    }
  }
}
```

```typescript
async function ensureTitle(input: {
  session: Session.Info
  modelID: string
  providerID: string
  history: MessageV2.WithParts[]
}) {
  // 如果是默认标题则生成新标题
  if (!Session.isDefaultTitle(input.session.title)) return

  // 找到最后一个用户消息
  const lastUser = input.history.findLast((m) => m.info.role === "user")
  if (!lastUser) return

  // 提取文本部分
  const textPart = lastUser.parts.find((p) => p.type === "text" && !p.synthetic)

  if (!textPart) return

  // 使用 title 代理生成标题
  const agent = await Agent.get("title")
  const stream = await LLM.stream({
    agent,
    user: lastUser.info,
    tools: {},
    model: await Provider.getModel(agent.model.providerID, agent.model.modelID),
    messages: [
      {
        role: "user",
        content: `生成以下文本的简短标题:\n\n${textPart.text}`,
      },
    ],
    abort: new AbortController().signal,
    sessionID: input.session.id,
    system: [],
    small: true,
  })

  const title = await stream.text

  // 更新会话标题
  await Session.update(input.session.id, (draft) => {
    draft.title = title
  })
}
```

### Diff 计算

```typescript
async function summarizeSession(input: { sessionID: string; messages: MessageV2.WithParts[] }) {
  // 提取所有修改的文件
  const files = new Set(
    input.messages
      .flatMap((x) => x.parts)
      .filter((x) => x.type === "patch")
      .flatMap((x) => x.files)
      .map((x) => path.relative(Instance.worktree, x)),
  )

  // 计算 diff
  const diffs = await computeDiff({ messages: input.messages }).then((x) => x.filter((x) => files.has(x.file)))

  // 更新会话摘要
  await Session.update(input.sessionID, (draft) => {
    draft.summary = {
      additions: diffs.reduce((sum, x) => sum + x.additions, 0),
      deletions: diffs.reduce((sum, x) => sum + x.deletions, 0),
      files: diffs.length,
    }
  })

  // 存储 diff 列表
  await Storage.write(["session_diff", input.sessionID], diffs)

  // 发布事件
  Bus.publish(Session.Event.Diff, {
    sessionID: input.sessionID,
    diff: diffs,
  })
}

async function computeDiff(input: { messages: MessageV2.WithParts[] }) {
  let from: string | undefined
  let to: string | undefined

  // 找到第一个和最后一个快照
  for (const item of input.messages) {
    for (const part of item.parts) {
      if (part.type === "step-start" && part.snapshot) {
        from = part.snapshot
      }
      if (part.type === "step-finish" && part.snapshot) {
        to = part.snapshot
      }
    }
  }

  if (from && to) return Snapshot.diffFull(from, to)
  return []
}
```

- **便捷的分享功能**：一键分享会话
