## 概述

OpenCode 使用 Vercel AI SDK 作为基础，构建了一个多提供商抽象层，使系统能够无缝支持多个 AI 提供商（OpenAI、Anthropic、Google、Amazon Bedrock 等），同时为上层提供统一的 API 接口。

### 核心设计原则

- **提供商无关**: 上层代码不需要关心底层提供商的具体实现
- **可扩展**: 通过插件系统和配置文件轻松添加新提供商
- **智能选择**: 自动选择最佳的 API 端点（如 OpenAI 的 Responses API vs Chat API）
- **性能优化**: 提供商实例缓存、请求超时、重试机制
- **错误映射**: 提供商特定的错误转换为统一的错误格式

### 核心文件

- `/packages/opencode/src/provider/provider.ts` - 提供商管理核心实现
- `/packages/opencode/src/provider/models.ts` - Models.dev API 集成
- `/packages/opencode/src/provider/transform.ts` - 提供商特定的消息和参数变换

## 统一 API 结构

### 核心函数

#### `getLanguage(model: Model)`

获取语言模型实例，返回符合 AI SDK 标准的 `LanguageModelV2` 对象：

```typescript
export async function getLanguage(model: Model): Promise<LanguageModelV2> {
  const s = await state()
  const key = `${model.providerID}/${model.id}`

  // 缓存模型实例
  if (s.models.has(key)) return s.models.get(key)!

  const provider = s.providers[model.providerID]
  const sdk = await getSDK(model)

  try {
    // 使用自定义加载器或默认方法
    const language = s.modelLoaders[model.providerID]
      ? await s.modelLoaders[model.providerID](sdk, model.api.id, provider.options)
      : sdk.languageModel(model.api.id)

    s.models.set(key, language)
    return language
  } catch (e) {
    if (e instanceof NoSuchModelError)
      throw new ModelNotFoundError(
        {
          modelID: model.id,
          providerID: model.providerID,
        },
        { cause: e },
      )
    throw e
  }
}
```

#### `getSDK(model: Model)`

获取或创建提供商 SDK 实例，支持缓存和动态安装：

```typescript
async function getSDK(model: Model) {
  const s = await state()
  const provider = s.providers[model.providerID]
  const options = { ...provider.options }

  // 设置基础 URL 和 API 密钥
  if (!options["baseURL"]) options["baseURL"] = model.api.url
  if (options["apiKey"] === undefined && provider.key) options["apiKey"] = provider.key

  // 缓存键（基于 npm 包和选项的哈希）
  const key = Bun.hash.xxHash32(JSON.stringify({ npm: model.api.npm, options }))
  const existing = s.sdk.get(key)
  if (existing) return existing

  // 自定义 fetch 处理超时和请求体转换
  options["fetch"] = async (input: any, init?: BunFetchRequestInit) => {
    const fetchFn = customFetch ?? fetch
    const opts = init ?? {}

    // 超时处理
    if (options["timeout"] !== undefined && options["timeout"] !== null) {
      const signals: AbortSignal[] = []
      if (opts.signal) signals.push(opts.signal)
      if (options["timeout"] !== false) signals.push(AbortSignal.timeout(options["timeout"]))

      opts.signal = signals.length > 1 ? AbortSignal.any(signals) : signals[0]
    }

    // OpenAI ID 元数据移除
    if (model.api.npm === "@ai-sdk/openai" && opts.body && opts.method === "POST") {
      const body = JSON.parse(opts.body as string)
      const isAzure = model.providerID.includes("azure")
      const keepIds = isAzure && body.store === true
      if (!keepIds && Array.isArray(body.input)) {
        for (const item of body.input) {
          if ("id" in item) delete item.id
        }
        opts.body = JSON.stringify(body)
      }
    }

    return fetchFn(input, { ...opts, timeout: false })
  }

  // 使用打包的提供商或动态安装
  const bundledKey = model.providerID === "google-vertex-anthropic" ? "@ai-sdk/google-vertex/anthropic" : model.api.npm
  const bundledFn = BUNDLED_PROVIDERS[bundledKey]

  if (bundledFn) {
    const loaded = bundledFn({ name: model.providerID, ...options })
    s.sdk.set(key, loaded)
    return loaded as SDK
  }

  // 动态安装提供商包
  const installedPath = await BunProc.install(model.api.npm, "latest")
  const mod = await import(installedPath)
  const fn = mod[Object.keys(mod).find((key) => key.startsWith("create"))!]
  const loaded = fn({ name: model.providerID, ...options })
  s.sdk.set(key, loaded)
  return loaded as SDK
}
```

### 流式响应部分

Vercel AI SDK 标准化流式响应部分类型：

- `text-delta` - 文本增量
- `tool-call` - 工具调用
- `tool-result` - 工具执行结果
- `finish` - 完成（包含 usage 统计）
- `error` - 错误
- `reasoning-delta` - 推理内容（部分模型）

### 提供商加载流程

1. **Models Dev**: 从 `models.dev` API 获取提供商/模型定义
2. **配置扩展**: 与本地配置（`opencode.json`）合并
3. **环境变量**: 从环境变量加载 API 密钥
4. **API 密钥**: 从存储的认证中加载
5. **插件**: 通过插件系统扩展
6. **自定义加载器**: 提供商特定的初始化逻辑

```typescript
const state = Instance.state(async () => {
  const modelsDev = await ModelsDev.get()
  const database = mapValues(modelsDev, fromModelsDevProvider)

  // 从配置扩展数据库
  for (const [providerID, provider] of configProviders) {
    const parsed: Info = {
      id: providerID,
      name: provider.name ?? existing?.name ?? providerID,
      env: provider.env ?? existing?.env ?? [],
      options: mergeDeep(existing?.options ?? {}, provider.options ?? {}),
      source: "config",
      models: existing?.models ?? {},
    }
    database[providerID] = parsed
  }

  // 加载环境变量
  const env = Env.all()
  for (const [providerID, provider] of Object.entries(database)) {
    if (disabled.has(providerID)) continue
    const apiKey = provider.env.map((item) => env[item]).find(Boolean)
    if (!apiKey) continue
    mergeProvider(providerID, {
      source: "env",
      key: provider.env.length === 1 ? apiKey : undefined,
    })
  }

  // 加载 API 密钥
  for (const [providerID, provider] of Object.entries(await Auth.all())) {
    if (disabled.has(providerID)) continue
    if (provider.type === "api") {
      mergeProvider(providerID, {
        source: "api",
        key: provider.key,
      })
    }
  }

  // 加载插件
  for (const plugin of await Plugin.list()) {
    if (!plugin.auth) continue
    const providerID = plugin.auth.provider
    const auth = await Auth.get(providerID)
    if (!auth || !plugin.auth.loader) continue

    const options = await plugin.auth.loader(() => Auth.get(providerID) as any, database[plugin.auth.provider])
    mergeProvider(plugin.auth.provider, {
      source: "custom",
      options: options,
    })
  }

  // 运行自定义加载器
  for (const [providerID, fn] of Object.entries(CUSTOM_LOADERS)) {
    if (disabled.has(providerID)) continue
    const data = database[providerID]
    if (!data) continue

    const result = await fn(data)
    if (result && (result.autoload || providers[providerID])) {
      if (result.getModel) modelLoaders[providerID] = result.getModel
      mergeProvider(providerID, {
        source: "custom",
        options: result.options,
      })
    }
  }

  return { models: languages, providers, sdk, modelLoaders }
})
```

### Amazon Bedrock 加载器

区域特定的模型 ID 前缀和凭证链：

```typescript
async amazon-bedrock() {
  const config = await Config.get()
  const providerConfig = config.provider?.["amazon-bedrock"]
  const auth = await Auth.get("amazon-bedrock")

  const defaultRegion = providerConfig?.options?.region ?? Env.get("AWS_REGION") ?? "us-east-1"
  const profile = providerConfig?.options?.profile ?? Env.get("AWS_PROFILE")

  const providerOptions: AmazonBedrockProviderSettings = { region: defaultRegion }

  // 凭证链（profile、access key、IAM role、web identity）
  if (!Env.get("AWS_BEARER_TOKEN_BEDROCK")) {
    const { fromNodeProviderChain } = await import("@aws-sdk/credential-providers")
    const credentialProviderOptions = profile ? { profile } : {}
    providerOptions.credentialProvider = fromNodeProviderChain(credentialProviderOptions)
  }

  return {
    autoload: true,
    options: providerOptions,
    async getModel(sdk: any, modelID: string, options?: Record<string, any>) {
      const region = options?.region ?? defaultRegion

      // 区域特定的模型 ID 前缀
      let regionPrefix = region.split("-")[0]
      if (modelID.startsWith("global.") || modelID.startsWith("jp.")) {
        return sdk.languageModel(modelID)
      }

      // 根据模型和区域添加前缀
      switch (regionPrefix) {
        case "us":
          if (["claude", "nova", "deepseek"].some(m => modelID.includes(m))) {
            modelID = `${regionPrefix}.${modelID}`
          }
          break
        case "eu":
          if (["claude", "nova", "llama3", "pixtral"].some(m => modelID.includes(m))) {
            modelID = `${regionPrefix}.${modelID}`
          }
          break
        case "ap":
          const regionRequiresPrefix = ["claude", "nova"].some(m => modelID.includes(m))
          if (regionRequiresPrefix) {
            regionPrefix = region.includes("ap-northeast-1") ? "jp" : "apac"
            modelID = `${regionPrefix}.${modelID}`
          }
          break
      }

      return sdk.languageModel(modelID)
    },
  }
}
```

## 提供商变换

ProviderTransform 模块提供提供商特定的消息、参数和选项变换：

### 消息变换

```typescript
export function message(messages: CoreMessage[], model: Model, options: Record<string, any>): CoreMessage[] {
  const providerID = model.providerID

  // Anthropic: 启用缓存
  if (providerID === "anthropic" && options.cacheControl) {
    return messages.map((msg) => ({
      ...msg,
      content:
        typeof msg.content === "string"
          ? [{ type: "text", text: msg.content, cache_control: { type: "ephemeral" } }]
          : msg.content,
    }))
  }

  // Mistral: 工具调用 ID 清理
  if (providerID === "mistral") {
    return messages.map((msg) => ({
      ...msg,
      content:
        typeof msg.content === "string"
          ? msg.content
          : msg.content.map((part) =>
              part.type === "tool-call"
                ? {
                    ...part,
                    toolCallId: part.toolCallId.replace(/[^a-zA-Z0-9]/g, "").slice(0, 9),
                  }
                : part,
            ),
    }))
  }

  return messages
}
```

```typescript
export function temperature(model: Model): number | undefined {
  // 提供商特定默认值
  if (model.api.id.includes("o1") || model.api.id.includes("o3")) return undefined
  if (model.api.id.includes("claude")) return 0.3

export function options(args: {
  model: Model
  sessionID: string
  providerOptions: Record<string, any>
}): Record<string, any> {
  const { model, providerOptions } = args

  const result: Record<string, any> = {}

  if (model.providerID === "anthropic") {
    result.cacheControl = true

  // OpenAI: store 选项（用于 ID 保留）
  if (model.api.npm === "@ai-sdk/openai") {
    result.store = false
  }

  return { ...result, ...providerOptions }
}
```

```typescript
    console.log(part.textDelta)
  }
}
```

## 总结

OpenCode 的 AI 提供商抽象层通过以下机制实现了提供商无关的统一接口：

1. **Vercel AI SDK 基础**: 使用标准化的 `LanguageModelV2` 接口
2. **提供商注册表**: 支持超过 20 个 AI 提供商
3. **自定义加载器**: 提供商特定的初始化和配置
4. **提供商变换**: 统一的消息和参数格式
5. **错误处理**: 结构化错误和用户友好的建议
6. **性能优化**: 实例缓存、超时、重试

开发者可以轻松添加新提供商或修改现有提供商行为，而无需改变上层代码。
