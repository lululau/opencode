## 概述

OpenCode 的工具系统是其核心功能之一，为 AI 代理提供了可扩展的能力框架。工具（Tool）是代理可以执行的具体操作，例如读取文件、运行 shell 命令、编辑代码、搜索内容等。

### 核心特性

- **类型安全**：使用 Zod schema 进行严格的参数验证和类型推断
- **权限控制**：细粒度的权限系统集成，确保安全执行
- **可扩展性**：通过插件系统和自定义工具轻松扩展
- **智能截断**：自动处理大型输出，避免超出 token 限制
- **异步执行**：完整的异步支持，包括取消和超时处理
- **元数据支持**：丰富的元数据用于追踪和调试

## 工具接口定义

### Tool.Info 接口

工具系统的核心是 `Tool.Info` 接口，定义在 `packages/opencode/src/tool/tool.ts`：

```typescript
export namespace Tool {
  // 元数据类型：工具可以返回任意类型的元数据
  interface Metadata {
    [key: string]: any
  }

  // 初始化上下文：工具初始化时传入的信息
  export interface InitContext {
    agent?: Agent.Info // 使用该工具的代理信息
  }

  // 执行上下文：工具执行时可用的上下文对象
  export type Context<M extends Metadata = Metadata> = {
    sessionID: string // 当前会话 ID
    messageID: string // 当前消息 ID
    agent: string // 代理名称
    abort: AbortSignal // 中止信号，用于取消长时间运行的工具
    callID?: string // 工具调用 ID
    extra?: { [key: string]: any } // 额外上下文数据
    metadata(input: { title?: string; metadata?: M }): void // 设置工具元数据
    ask(input: Omit<PermissionNext.Request, "id" | "sessionID" | "tool">): Promise<void> // 请求权限
  }

  // 工具信息接口
  export interface Info<Parameters extends z.ZodType = z.ZodType, M extends Metadata = Metadata> {
    id: string // 工具的唯一标识符
    init: (ctx?: InitContext) => Promise<{
      description: string // 工具描述，用于 AI 理解工具用途
      parameters: Parameters // Zod schema，定义工具参数
      execute(
        args: z.infer<Parameters>, // 验证后的参数
        ctx: Context<M>, // 执行上下文
      ): Promise<{
        title: string // 工具执行的标题
        metadata: M // 返回的元数据
        output: string // 工具输出内容
        attachments?: MessageV2.FilePart[] // 可选的附件（如图片、文件）
      }>
      formatValidationError?(error: z.ZodError): string // 自定义验证错误格式化
    }>
  }

  // 类型推断工具
  export type InferParameters<T extends Info> = T extends Info<infer P> ? z.infer<P> : never
  export type InferMetadata<T extends Info> = T extends Info<any, infer M> ? M : never
}
```

### Tool.define 工厂方法

`Tool.define` 是创建工具定义的工厂方法：

```typescript
export function define<Parameters extends z.ZodType, Result extends Metadata>(
  id: string,
  init: Info<Parameters, Result>["init"] | Awaited<ReturnType<Info<Parameters, Result>["init"]>>,
): Info<Parameters, Result> {
  return {
    id,
    init: async (initCtx) => {
      const toolInfo = init instanceof Function ? await init(initCtx) : init
      const execute = toolInfo.execute

      // 包装 execute 方法以添加自动验证和截断
      toolInfo.execute = async (args, ctx) => {
        // 1. 参数验证
        try {
          toolInfo.parameters.parse(args)
        } catch (error) {
          if (error instanceof z.ZodError && toolInfo.formatValidationError) {
            throw new Error(toolInfo.formatValidationError(error), { cause: error })
          }
          throw new Error(
            `The ${id} tool was called with invalid arguments: ${error}.\nPlease rewrite the input so it satisfies the expected schema.`,
            { cause: error },
          )
        }

        // 2. 执行工具
        const result = await execute(args, ctx)

        // 3. 输出截断（如果工具未自己处理）
        if (result.metadata.truncated !== undefined) {
          return result
        }
        const truncated = await Truncate.output(result.output, {}, initCtx?.agent)
        return {
          ...result,
          output: truncated.content,
          metadata: {
            ...result.metadata,
            truncated: truncated.truncated,
            ...(truncated.truncated && { outputPath: truncated.outputPath }),
          },
        }
      }
      return toolInfo
    },
  }
}
```

**设计亮点**：

1. **自动参数验证**：工具执行前自动验证参数，无需手动处理
2. **可截断标记**：工具可以设置 `metadata.truncated` 来跳过自动截断
3. **类型安全**：完整的 TypeScript 类型推断和泛型支持
4. **异步初始化**：支持工具初始化时进行异步操作

### 参数验证流程

参数验证在工具执行前自动进行：

```
1. AI 生成工具调用
   ↓
2. Tool.define 包装器接收参数
   ↓
3. Zod schema 验证
   ├─ 成功 → 继续执行
   └─ 失败 → 抛出错误
        ├─ formatValidationError 存在？
        │  ├─ 是 → 使用自定义错误消息
        │  └─ 否 → 使用默认错误消息
        └─ 错误包含 cause 和详细错误信息
```

## 工具执行流程

### 完整执行生命周期

```
1. 工具初始化 (init)
   ├─ 加载配置和依赖
   ├─ 创建工具信息对象
   └─ 返回 { description, parameters, execute, formatValidationError }

2. 工具调用
   ├─ AI 选择工具和参数
   ├─ 调用 tool.init() 获取工具信息
   └─ 返回工具定义

3. 参数验证
   ├─ toolInfo.parameters.parse(args)
   ├─ 验证成功 → 继续
   └─ 验证失败 → 抛出 ZodError

4. 权限检查
   ├─ ctx.ask({ permission: "...", patterns: [...] })
   ├─ 权限评估
   ├─ allow → 继续
   ├─ ask → 等待用户批准
   └─ deny → 抛出 DeniedError

5. 工具执行 (execute)
   ├─ 执行工具逻辑
   ├─ 返回 { title, metadata, output, attachments }
   └─ 处理错误和异常

6. 输出处理
   ├─ 检查 metadata.truncated
   ├─ 未标记 → 自动截断
   ├─ 已标记 → 使用原始输出
   └─ 返回最终结果

7. 元数据更新
   ├─ ctx.metadata() 更新工具元数据
   └─ 事件发布（如文件编辑）
```

### 执行代码示例

```typescript
export const ReadTool = Tool.define("read", {
  description: DESCRIPTION,
  parameters: z.object({
    filePath: z.string(),
    offset: z.coerce.number().optional(),
    limit: z.coerce.number().optional(),
  }),
  async execute(params, ctx) {
    // 1. 参数已验证，直接使用
    let filepath = params.filePath
    if (!path.isAbsolute(filepath)) {
      filepath = path.join(process.cwd(), filepath)
    }

    // 2. 权限检查
    await ctx.ask({
      permission: "read",
      patterns: [filepath],
      always: ["*"],
      metadata: {},
    })

    // 3. 执行工具逻辑
    const file = Bun.file(filepath)
    if (!(await file.exists())) {
      throw new Error(`File not found: ${filepath}`)
    }

    const lines = await file.text().then((text) => text.split("\n"))
    const limit = params.limit ?? DEFAULT_READ_LIMIT
    const offset = params.offset || 0

    // 4. 返回结果
    return {
      title: path.relative(process.cwd(), filepath),
      output: formatOutput(lines, offset, limit),
      metadata: {
        truncated: lines.length > offset + limit,
      },
    }
  },
})
```

### Context 对象详解

`Context` 对象提供了工具执行时需要的所有上下文信息和方法：

### 使用示例

#### 1. 获取会话信息

```typescript
async execute(args, ctx) {
```

#### 2. 处理中止信号

```typescript
async execute(args, ctx) {
  const proc = spawn(params.command, {
    cwd: workdir,
  })

  // 监听中止信号
  if (ctx.abort.aborted) {
    await killProcess(proc)
    throw new Error("Tool execution was aborted")
  }

  const abortHandler = () => {
    killProcess(proc)
  }

  ctx.abort.addEventListener("abort", abortHandler, { once: true })

  try {
    const result = await runCommand(proc)
    return result
  } finally {
    ctx.abort.removeEventListener("abort", abortHandler)
  }
}
```

## 输出截断机制

### Truncate 模块

`Truncate` 模块（`packages/opencode/src/tool/truncation.ts`）提供了智能输出截断功能：

```typescript
export namespace Truncate {
  export const MAX_LINES = 2000
  export const MAX_BYTES = 50 * 1024 // 50KB
  export const DIR = path.join(Global.Path.data, "tool-output")
  export const GLOB = path.join(DIR, "*")
  const RETENTION_MS = 7 * 24 * 60 * 60 * 1000 // 7 days
}
```

### 截断逻辑

```typescript
export async function output(text: string, options: Options = {}, agent?: Agent.Info): Promise<Result> {
  const maxLines = options.maxLines ?? MAX_LINES
  const maxBytes = options.maxBytes ?? MAX_BYTES
  const direction = options.direction ?? "head"

  const lines = text.split("\n")
  const totalBytes = Buffer.byteLength(text, "utf-8")

  // 检查是否需要截断
  if (lines.length <= maxLines && totalBytes <= maxBytes) {
    return { content: text, truncated: false }
  }

  // 执行截断（head 或 tail）
  const out: string[] = []
  let bytes = 0

  if (direction === "head") {
    for (let i = 0; i < lines.length && i < maxLines; i++) {
      const size = Buffer.byteLength(lines[i], "utf-8") + (i > 0 ? 1 : 0)
      if (bytes + size > maxBytes) break
      out.push(lines[i])
      bytes += size
    }
  } else {
    for (let i = lines.length - 1; i >= 0 && out.length < maxLines; i--) {
      const size = Buffer.byteLength(lines[i], "utf-8") + (out.length > 0 ? 1 : 0)
      if (bytes + size > maxBytes) break
      out.unshift(lines[i])
      bytes += size
    }
  }

  // 保存完整输出到文件
  const id = Identifier.ascending("tool")
  const filepath = path.join(DIR, id)
  await Bun.write(Bun.file(filepath), text)

  // 生成提示消息
  const hint = hasTaskTool(agent)
    ? `The tool call succeeded but output was truncated. Full output saved to: ${filepath}\nUse Task tool to have explore agent process this file with Grep and Read (with offset/limit). Do NOT read the full file yourself - delegate to save context.`
    : `The tool call succeeded but output was truncated. Full output saved to: ${filepath}\nUse Grep to search the full content or Read with offset/limit to view specific sections.`

  const message =
    direction === "head"
      ? `${preview}\n\n...${removed} ${unit} truncated...\n\n${hint}`
      : `...${removed} ${unit} truncated...\n\n${hint}\n\n${preview}`

  return { content: message, truncated: true, outputPath: filepath }
}
```

### 权限模型

OpenCode 使用细粒度的权限系统（详见 `08-权限系统设计.md`）：


### 工具中的权限检查

工具通过 `ctx.ask()` 请求权限：

```typescript

      operation: "read",

    patterns: [path.relative(Instance.worktree, filepath)],

    metadata: {
      filepath,
      diff,  // 显示差异
    },
  })

  // 请求 bash 执行权限
  await ctx.ask({
    permission: "bash",
    patterns: [command],
    always: [BashArity.prefix(command).join(" ") + "*"],
    metadata: {
      command: command,
    },
  })
}
```

### 权限评估流程

```
工具调用 ctx.ask()
  ↓
PermissionNext.ask()
  ↓
遍历所有模式（patterns）
  ├─ evaluate(permission, pattern, ruleset, approved)
  │  ├─ 查找匹配规则
  │  ├─ 返回 { action, ... }
  │  └─ action === "deny" → 抛出 DeniedError
  │
  ├─ action === "ask" → 等待用户批准
  │  ├─ 发布 Event.Asked
  │  ├─ 存储到 pending
  │  └─ 等待 Event.Replied
  │     ├─ once → 执行一次
  │     ├─ always → 记录到 approved
  │     └─ reject → 抛出错误
  │
  └─ action === "allow" → 继续
```

## 工具注册机制

### ToolRegistry 模块

`ToolRegistry`（`packages/opencode/src/tool/registry.ts`）负责工具的发现、注册和管理：

```typescript
export namespace ToolRegistry {
  // 状态管理
  export const state = Instance.state(async () => {
    const custom = [] as Tool.Info[]

    // 1. 加载本地自定义工具
    const glob = new Bun.Glob("{tool,tools}/*.{js,ts}")
    for (const dir of await Config.directories()) {
      for await (const match of glob.scan({ cwd: dir, absolute: true })) {
        const namespace = path.basename(match, path.extname(match))
        const mod = await import(match)
        for (const [id, def] of Object.entries<ToolDefinition>(mod)) {
          custom.push(fromPlugin(id === "default" ? namespace : `${namespace}_${id}`, def))
        }
      }
    }

    // 2. 加载插件工具
    const plugins = await Plugin.list()
    for (const plugin of plugins) {
      for (const [id, def] of Object.entries(plugin.tool ?? {})) {
        custom.push(fromPlugin(id, def))
      }
    }

    return { custom }
  })

  // 注册工具
  export async function register(tool: Tool.Info) {
    const { custom } = await state()
    const idx = custom.findIndex((t) => t.id === tool.id)
    if (idx >= 0) {
      custom.splice(idx, 1, tool) // 替换已存在的工具
      return
    }
    custom.push(tool)
  }
}
```

```typescript
    tools

          return model.providerID === "opencode" || Flag.OPENCODE_ENABLE_EXA
        }

        // 补丁工具：用于 OpenAI GPT 模型
        const usePatch =
          model.modelID.includes("gpt-") && !model.modelID.includes("oss") && !model.modelID.includes("gpt-4")
        if (t.id === "apply_patch") return usePatch
        if (t.id === "edit" || t.id === "write") return !usePatch

        if (t.id === "todoread" || t.id === "todowrite") {
          if (model.modelID.includes("gpt-")) return false
        }

        return true
      })
      .map(async (t) => {
        using _ = log.time(t.id)
        return {
          id: t.id,
          ...(await t.init({ agent })), // 初始化工具
        }
      }),
  )

  return result
```
