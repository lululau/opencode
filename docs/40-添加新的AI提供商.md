## 概述

本教程将带你从零开始添加一个新的 AI 提供商到 OpenCode。我们将以一个实际的案例——**添加一个假设的自定义 AI 提供商**为例，展示完整的集成流程。

### 什么是 AI 提供商？

AI 提供商是 OpenCode 抽象层的一部分，它：

- 统一不同 AI 服务的接口
- 处理认证和 API 密钥管理
- 提供模型信息和能力
- 管理流式响应和工具调用

### OpenCode 支持的提供商

| 提供商           | 说明          | SDK 包                  |
| ---------------- | ------------- | ----------------------- |
| **Anthropic**    | Claude 模型   | `@anthropic-ai/sdk`     |
| **OpenAI**       | GPT 模型      | `openai`                |
| **Google**       | Gemini 模型   | `@google/generative-ai` |
| **Azure OpenAI** | 托管的 OpenAI | `@azure/openai`         |
| **Mistral**      | Mistral 模型  | `@mistralai/mistralai`  |
| **Groq**         | 快速推理      | `groq-sdk`              |
| **Together AI**  | 开源模型      | `@together-ai/sdk`      |

## 提供商接口

### Provider 接口定义

查看提供商接口（`/Users/liuxiang/cascode/github.com/opencode/packages/opencode/src/provider/provider.ts`）：

```typescript
interface Provider {
  id: string // 提供商唯一标识
  name: string // 提供商名称
  source: "env" | "config" | "custom" | "api" | "well-known"
  env: string[] // 环境变量名称
  key?: string // API Key（可选）
  options: Record<string, any> // 提供商特定选项
  models: {
    // 模型数据库
    [modelID: string]: ModelInfo
  }
}
```

### ModelInfo 接口

```typescript
interface ModelInfo {
  id: string // 模型 ID
  name: string // 模型显示名称
  family: string // 模型系列（如 claude, gpt）
  status: string // 状态（beta, stable, deprecated）
  providerID: string // 提供商 ID

  capabilities: {
    temperature: boolean // 支持温度参数
    reasoning: boolean // 支持推理
    attachment: boolean // 支持附件
    toolcall: boolean // 支持工具调用
    input: string // 输入类型（text, image, audio）
    output: string // 输出类型（text, json）
    interleaved: boolean // 支持交输出
  }

  cost: {
    input: number // 输入价格（每百万 token）
    output: number // 输出价格（每百万 token）
    cache: {
      // 缓存价格
      read: number
      write: number
    }
  }

  limit: {
    context: number // 上下文窗口（token）
    input: number // 输入限制（token）
    output: number // 输出限制（token）
  }

  api: {
    id: string // API 模型 ID
    url: string // API 端点 URL
    npm: string // SDK npm 包名
  }

  options: Record<string, any> // 模型特定选项
  headers: Record<string, string> // 请求头

  releaseDate: string // 发布日期
  variants: string[] // 变体列表
}
```

### 提供商加载流程

```
1. 加载内置提供商
   └─> Provider.state() 初始化

2. 加载远程 well-known 配置
   └─> https://domain/.well-known/opencode

3. 加载环境变量
   └─> 检查 provider.env 数组

4. 加载配置中的 API Key
   └─> 从 auth 数据库加载

5. 加载插件认证
   └─> 调用 plugin.auth

6. 加载自定义加载器
   └─> CUSTOM_LOADERS 特殊处理

7. 合并所有提供商
   └─> 生成最终提供商列表
```

## 认证处理

### 认证方式

OpenCode 支持多种认证方式：

| 认证方式         | 说明                     | 适用场景        |
| ---------------- | ------------------------ | --------------- |
| **环境变量**     | 通过环境变量传递 API Key | 生产环境、CI/CD |
| **配置文件**     | 在 opencode.json 中存储  | 开发环境        |
| **数据库**       | 加密存储在 auth 数据库   | 持久化存储      |
| **插件**         | 通过插件实现特殊认证     | OAuth、特殊流程 |
| **自定义加载器** | 提供商特定的加载逻辑     | 复杂认证流程    |

### 实现自定义认证加载器

在 `CUSTOM_LOADERS` 中添加：

```typescript
// /Users/liuxiang/cascode/github.com/opencode/packages/opencode/src/provider/provider.ts

const CUSTOM_LOADERS = {
  // 现有加载器...

  // 新增 CustomAI 认证加载器
  customai: async (provider: Provider) => {
    const apiKey = provider.key || process.env.CUSTOMAI_API_KEY

    if (!apiKey) {
      throw new Error("CustomAI API Key 未设置")
    }

    // 自定义 API Key 验证
    const isValid = await validateCustomApiKey(apiKey)

    if (!isValid) {
      throw new Error("CustomAI API Key 无效")
    }

    // 返回提供商选项
    return {
      apiKey,
      baseURL: provider.options?.baseURL || "https://api.customai.com/v1",
      headers: {
        ...provider.options?.headers,
        Authorization: `Bearer ${apiKey}`,
        "X-API-Version": "2024-01-01",
      },
      timeout: provider.options?.timeout || 30000,
    }
  },
}

// API Key 验证函数
async function validateCustomApiKey(apiKey: string): Promise<boolean> {
  try {
    const response = await fetch("https://api.customai.com/v1/validate", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ key: apiKey }),
    })

    const data = await response.json()
    return data.valid === true
  } catch {
    return false
  }
}
```

### OAuth 认证

对于需要 OAuth 的提供商：

```typescript
const CUSTOM_LOADERS = {
  oauthprovider: async (provider: Provider) => {
    // 检查是否已存储令牌
    const auth = await Auth.getForUrl("oauthprovider", "https://api.oauthprovider.com")

    if (auth?.tokens?.accessToken) {
      return {
        accessToken: auth.tokens.accessToken,
        refreshToken: auth.tokens.refreshToken,
        baseURL: provider.options?.baseURL,
      }
    }

    // 触发 OAuth 流程
    throw new Error("需要 OAuth 认证。请运行: opencode auth oauthprovider")
  },
}
```

### 单元测试

创建 `test/provider.test.ts`:

```typescript
import { describe, it, expect } from "bun:test"
import { Provider } from "../src/provider/provider"
import { ModelsDev } from "../src/provider/models"

describe("CustomAI Provider", () => {
  it("应该加载提供商配置", () => {
    const provider = Provider.customai

    expect(provider).toBeDefined()
    expect(provider.id).toBe("customai")
    expect(provider.name).toBe("CustomAI")
  })

  it("应该加载模型配置", () => {
    const models = ModelsDev.get()
    const model = models.customai?.["custom-model-1"]

    expect(model).toBeDefined()
    expect(model.name).toBe("Custom Model v1")
    expect(model.capabilities.toolcall).toBe(true)
  })

  it("应该验证 API Key", async () => {
    const loader = CUSTOM_LOADERS.customai

    // 有效 Key
    const result1 = await loader({
      key: "valid-api-key-12345",
      options: {},
    })

    expect(result1.apiKey).toBe("valid-api-key-12345")

    // 无效 Key
    await expect(loader({ key: "", options: {} })).rejects.toThrow()
  })

  it("应该从环境变量读取 API Key", () => {
    process.env.CUSTOMAI_API_KEY = "env-api-key"

    const provider = Provider.customai

    expect(provider.env).toContain("CUSTOMAI_API_KEY")
  })
})
```

// CUSTOM_LOADERS
customprovider: async (provider: Provider) => {
  const apiKey = provider.key || process.env.CUSTOMPROVIDER_API_KEY

  if (!apiKey) {
    throw new Error("CustomProvider API Key 未设置")
  }

  // 自定义认证流程
  const authResult = await authenticateWithCustomProvider(apiKey)

  return {
    apiKey: authResult.accessToken,
    baseURL: provider.options?.baseURL,
    headers: {
      "X-Custom-Auth": authResult.customHeader,
      "User-Agent": "OpenCode/1.0.0"
    },
    timeout: provider.options?.timeout || 30000,
    // 添加提供商特定选项
    ...authResult.extraOptions
  }
}

// 自定义认证函数
async function authenticateWithCustomProvider(apiKey: string) {
  const response = await fetch("https://api.customprovider.com/v1/auth", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({ apiKey })
  })

  const data = await response.json()

  if (!data.success) {
    throw new Error(`认证失败: ${data.error}`)
  }

  return {
    accessToken: data.accessToken,
    customHeader: data.customToken,
    extraOptions: {
      region: data.region,
      featureFlags: data.features
    }
  }
}
