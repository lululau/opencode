## 概述

OpenCode 使用**分层、多层的提示词架构**，提供灵活、可扩展的提示词管理系统。系统支持提供商特定的提示词、自定义指令、上下文压缩和动态提示词插入。

### 核心设计原则

- **模块化**: 40+ 个独立的提示词文件用于不同上下文
- **提供商感知**: 不同模型有不同的提示词策略
- **上下文优先**: 支持 AGENTS.md、CLAUDE.md 等项目约定
- **Token 高效**: 缓存优化、压缩策略、delta 更新
- **可扩展**: 插件钩子允许自定义提示词转换

### 核心文件

- `/packages/opencode/src/session/system.ts` - 系统提示词管理和提供商特定提示词
- `/packages/opencode/src/session/prompt.ts` - 会话级提示词处理和消息循环
- `/packages/opencode/src/session/compaction.ts` - 自动上下文压缩
- `/packages/opencode/src/session/llm.ts` - LLM 调用的提示词组装

**自定义函数**（`system.ts` - lines 94-155）：

```typescript
export async function custom() {
  const config = await Config.get()
  const paths = new Set<string>()

  // 1. 扫描本地规则文件（仅在启用项目发现时）
  if (!Flag.OPENCODE_DISABLE_PROJECT_CONFIG) {
    for (const localRuleFile of LOCAL_RULE_FILES) {
      const matches = await Filesystem.findUp(localRuleFile, Instance.directory, Instance.worktree)
      if (matches.length > 0) {
        matches.forEach((path) => paths.add(path))
        break
      }
    }
  }

  // 2. 扫描全局规则文件
  for (const globalRuleFile of GLOBAL_RULE_FILES) {
    if (await Bun.file(globalRuleFile).exists()) {
      paths.add(globalRuleFile)
      break
    }
  }

  // 3. 从配置加载指令
  if (config.instructions) {
    for (let instruction of config.instructions) {
      // HTTP/HTTPS URL
      if (instruction.startsWith("https://") || instruction.startsWith("http://")) {
        urls.push(instruction)
        continue
      }

      // 家目录路径（~/）
      if (instruction.startsWith("~/")) {
        instruction = path.join(os.homedir(), instruction.slice(2))
      }

      // 绝对路径
      let matches: string[] = []
      if (path.isAbsolute(instruction)) {
        matches = await Array.fromAsync(
          new Bun.Glob(path.basename(instruction)).scan({
            cwd: path.dirname(instruction),
            absolute: true,
            onlyFiles: true,
          }),
        ).catch(() => [])
      } else {
        // 相对路径
        matches = await resolveRelativeInstruction(instruction)
      }

      matches.forEach((path) => paths.add(path))
    }
  }

  // 4. 读取所有文件和 URL
  const foundFiles = Array.from(paths).map((p) =>
    Bun.file(p)
      .text()
      .catch(() => "")
      .then((x) => "Instructions from: " + p + "\n" + x),
  )
  const foundUrls = urls.map((url) =>
    fetch(url, { signal: AbortSignal.timeout(5000) })
      .then((res) => (res.ok ? res.text() : ""))
      .catch(() => "")
      .then((x) => (x ? "Instructions from: " + url + "\n" + x : "")),
  )
  return Promise.all([...foundFiles, ...foundUrls]).then((result) => result.filter(Boolean))
}
```

### 模板解析

`resolvePromptParts()` 函数（`prompt.ts` - lines 182-231）：

```typescript
async function resolvePromptParts(prompt: string): Promise<PromptPart[]> {
  const parts: PromptPart[] = []

  for (const match of prompt.matchAll(/\[\[(.+?)\]/g)) {
    const full = match[0]
    const content = match[1]

    // 文件路径
    if (await Bun.file(content).exists()) {
      parts.push({ type: "file", value: content })
      continue
    }

    // 目录
    if (await isDirectory(content)) {
      parts.push({ type: "directory", value: content })
      continue
    }

    // 绝对路径
    if (path.isAbsolute(content)) {
      parts.push({ type: "path", value: content })
      continue
    }

    // 家目录路径（~/）
    if (content.startsWith("~/")) {
      const resolved = path.join(os.homedir(), content.slice(2))
      parts.push({ type: "path", value: resolved })
      continue
    }

    // 代理引用
    if (agents[content]) {
      parts.push({ type: "agent", value: content })
      continue
    }

    // 符号引用
    if (content.includes("#")) {
      const [file, symbol] = content.split("#")
      parts.push({ type: "symbol", file, symbol })
      continue
    }
  }

  return parts
}
```

支持的引用语法：

- `[[path/to/file]]` - 文件内容
- `[[path/to/directory]]` - 目录
- `[[agent-name]]` - 代理调用
- `[[file#symbol]]` - LSP 符号

## 总结

OpenCode 的提示词工程系统通过以下机制实现：

1. **模块化提示词文件**：40+ 个独立 `.txt` 文件用于不同上下文
2. **提供商感知**：不同提供商使用不同的提示词策略
3. **多层级上下文**：全局 → 项目 → 会话 → 消息
4. **自动压缩**：Token 超限时触发智能修剪
5. **模板系统**：`[[...]]` 语法用于文件、目录、符号、代理引用
6. **插件扩展**：钩子允许自定义提示词转换
7. **优化策略**：缓存、并行工具、delta 更新、多阶段工作流

**关键模式：**

- 尊重用户项目约定（AGENTS.md、CLAUDE.md）
- 支持提供商特定的功能（推理、缓存、工具调用）
- 自动上下文管理以维持对话效率
- 灵活的模板系统用于快速引用

该系统使开发者能够轻松自定义 AI 行为，同时保持与现有代码的一致性。
