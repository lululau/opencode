## 概述

OpenCode 支持 **75+ 个 LLM 提供商**和 **1000+ 个模型**，通过 [Models.dev](https://models.dev) API 统一管理。系统提供灵活的模型选择机制，支持提供商特定的功能和配置。

### 核心特性

- **提供商无关**: 统一的接口，轻松切换提供商
- **自动发现**: 从 Models.dev API 动态获取模型
- **智能路由**: 根据任务自动选择最佳模型
- **推理支持**: 支持带推理预算的模型（Claude、GPT-5 等）
- **成本优化**: 缓存支持、模型变体、自动压缩
- **多模态**: 支持文本、图像、音频、视频输入输出

## 模型能力

### 核心能力

每个模型都定义了以下能力：

```typescript
capabilities: {
  temperature: boolean,      // 支持温度参数
  reasoning: boolean,        // 支持思考/推理
  attachment: boolean,       // 支持文件附件
  toolcall: boolean,        // 支持函数调用
  input: {
    text: boolean,
    audio: boolean,
    image: boolean,
    video: boolean,
    pdf: boolean
  },
  output: {
    text: boolean,
    audio: boolean,
    image: boolean,
    video: boolean,
    pdf: boolean
  },
  interleaved: boolean | {
    field: "reasoning_content" | "reasoning_details"
  }
}
```

### 模型变体（推理努力级别）

#### OpenAI 模型（`gpt-5`、`o1`、`o3`、`o4-mini`、`azure`）

```javascript
{
  "none": { reasoningEffort: "none" },      // 无推理
  "minimal": { reasoningEffort: "minimal" }, // 快速推理
  "low": { reasoningEffort: "low" },
  "medium": { reasoningEffort: "medium" },
  "high": { reasoningEffort: "high" },
  "xhigh": { reasoningEffort: "xhigh" }  // 最大推理
}
```

#### Anthropic 模型

```javascript
{
  "high": { thinking: { type: "enabled", budgetTokens: 16000 } },
  "max": { thinking: { type: "enabled", budgetTokens: 31999 } }
}
```

#### Google/Gemini 模型（`gemini-2.5`）

```javascript
{
  "high": { thinkingConfig: { includeThoughts: true, thinkingBudget: 16000 } },
  "max": { thinkingConfig: { includeThoughts: true, thinkingBudget: 24576 } }
}
```

#### Grok 模型

```javascript
{
  "low": { reasoningEffort: "low" },
  "high": { reasoningEffort: "high" }
}
```

### 模型限制

每个模型都定义了：

```typescript
limit: {
  context: number,  // 最大上下文窗口（tokens）
  output: number   // 最大输出 tokens
}
```

示例：

- `gpt-5`: context 200K+, output 可变
- `claude-sonnet-4.5`: context 200K+, output 8K
- `gemini-2.0-flash`: context 1M, output 8K
- `gpt-5-nano`: context 32K, output 32K
- `claude-haiku-4.5`: context 200K+, output 8K

### 模型加载流程

```typescript
// 1. 从 Models.dev API 获取（缓存到 ~/.opencode/cache/models.json）
const models = await ModelsDev.get()

// 2. 与配置文件模型合并
for (const [providerID, provider] of configProviders) {
  mergeProvider(providerID, provider)
}

// 3. 加载环境变量
for (const [providerID, provider] of Object.entries(database)) {
  const apiKey = provider.env.map((item) => env[item]).find(Boolean)
  if (apiKey) mergeProvider(providerID, { source: "env", key: apiKey })
}

// 4. 从认证存储加载 API 密钥
for (const [providerID, provider] of Object.entries(await Auth.all())) {
  if (provider.type === "api") {
    mergeProvider(providerID, { source: "api", key: provider.key })
  }
}

// 5. 应用自定义加载器（特定配置）
CUSTOM_LOADERS: {
  anthropic: { options: { "anthropic-beta": "..." } },
  openai: { getModel: (sdk, id) => sdk.responses(id) },
  github-copilot: {
    getModel: (sdk, id) =>
      shouldUseCopilotResponsesApi(id) ? sdk.responses(id) : sdk.chat(id)
  }
}

// 6. 根据 enabled_providers / disabled_providers 过滤
// 7. 除非 OPENCODE_ENABLE_EXPERIMENTAL_MODELS=true 否则过滤 alpha 模型
// 8. 移除已弃用的模型
// 9. 按提供商应用白名单/黑名单
```

### 模型解析

```typescript
function parseModel(model: string): { providerID: string; modelID: string } {
  const [providerID, ...rest] = model.split("/")
  return { providerID, modelID: rest.join("/") }
}

// 示例：
parseModel("anthropic/claude-sonnet-4.5")
// => { providerID: "anthropic", modelID: "claude-sonnet-4.5" }

parseModel("openai/gpt-5-nano")
// => { providerID: "openai", modelID: "gpt-5-nano" }
```

### 特殊提供商行为

#### Anthropic

- 使用 Claude Code 头部：`claude-code-20250219,interleaved-thinking-2025-05-14,fine-grained-tool-streaming-2025-05-14`
- 对系统消息和最后 2 条用户消息应用缓存控制
- 支持提示词缓存以节省成本

#### OpenAI

- GPT-5+ 默认使用 Responses API（`sdk.responses(modelID)`）
- 默认设置 `store: false`（不持久化对话）
- 从请求体中移除 `itemId`
- 支持会话级缓存的 `promptCacheKey`
- GPT-5 的文本详细程度默认为 "low"

#### GitHub Copilot

- 较旧模型使用 `chat(modelID)`
- GPT-5+（不包括 gpt-5-mini）使用 `responses(modelID)`
- 添加 `Openai-Intent: conversation-edits` 头部

#### Azure

- 支持 chat 和 responses 端点
- `useCompletionUrls` 选项控制使用哪个端点
- 某些模型的区域前缀

#### Amazon Bedrock

- 支持凭证链（profiles、access keys、IAM roles、web identity）
- 感知的模型前缀：
  - US: `us.model-id`
  - EU: `eu.model-id`
  - APAC: `apac.model-id` / `jp.model-id` / `au.model-id`
- Bearer token 优先于凭证链
- 跨区域推理：`global.` 和 `jp.` 前缀的模型跳过前缀

#### Google / Vertex

- 需要项目和位置配置
- Vertex Anthropic 使用子路径：`@ai-sdk/google-vertex/anthropic`

#### OpenRouter

- 添加头部：`HTTP-Referer: https://opencode.ai/`、`X-Title: opencode`
- 启用 `usage.include: true`

### 模型过滤

```typescript
// 按状态禁用模型
if (model.status === "alpha" && !OPENCODE_ENABLE_EXPERIMENTAL_MODELS) delete
if (model.status === "deprecated") delete

// 提供商级过滤

    (providerID === "openrouter" && modelID === "openai/gpt-5-chat"))
  delete provider.models[modelID]
```

## 总结

**OpenCode 支持 75+ 个提供商和 1000+ 个模型**，全部通过以下方式管理：

1. **Models.dev API** - 从 `https://models.dev/api.json` 获取的中央目录
2. **打包的 SDK** - 主要提供商的直接集成
3. **OpenAI 兼容 API** - 60+ 个其他提供商的通用适配器
4. **自定义配置** - 覆盖模型、添加自定义提供商
5. **Zen 服务** - 优化的模型路由和回退提供商

**需要了解的关键模型系列：**

- **GPT-5 系列** - 最新的 OpenAI 推理模型
- **Claude Sonnet 4.5** - 代码代理的最佳选择
- **Claude Opus 4.5** - 高级推理
- **Claude Haiku 4.5** - 快速、成本高效
- **Gemini 2.0 Flash** - 1M 上下文窗口
- **Grok 3-mini** - xAI 推理
- **Qwen 3** - 阿里的高级模型

- **Nova 系列** - AWS 模型

**默认模型：**
