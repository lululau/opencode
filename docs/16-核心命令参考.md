## 命令概述

OpenCode CLI 提供了一组强大的命令行工具，用于管理开发会话、代理、认证、配置和扩展功能。

### 命令分类

| 类别       | 命令                          | 描述                     |
| ---------- | ----------------------------- | ------------------------ |
| **交互**   | `run`、`$0` (默认)            | 运行 OpenCode 交互会话   |
| **服务器** | `serve`、`web`                | 启动服务器或 Web 界面    |
| **认证**   | `auth`                        | 管理提供商凭证           |
| **代理**   | `agent`                       | 管理和创建代理           |
| **MCP**    | `mcp`                         | 管理 MCP 服务器          |
| **会话**   | `session`、`export`、`import` | 会话管理和数据导出/导入  |
| **GitHub** | `github`、`pr`                | GitHub 集成和 PR 管理    |
| **工具**   | `models`、`debug`、`generate` | 模型查询、调试和工具生成 |
| **系统**   | `upgrade`、`stats`、`acp`     | 升级、统计和协议服务     |

## 全局选项

以下选项可用于所有命令：

| 选项           | 简写 | 类型    | 默认                                       | 描述 |
| -------------- | ---- | ------- | ------------------------------------------ | ---- |
| `--help`       | `-h` | -       | 显示帮助信息                               |
| `--version`    | `-v` | -       | 显示版本号                                 |
| `--print-logs` | -    | `false` | 将日志输出到 stderr                        |
| `--log-level`  | -    | `INFO`  | 日志级别：`DEBUG`、`INFO`、`WARN`、`ERROR` |

### 网络选项（适用于需要网络配置的命令）

| 选项         | 类型    | 默认        | 描述                             |
| ------------ | ------- | ----------- | -------------------------------- |
| `--port`     | number  | `0`         | 端口号（0 表示随机端口）         |
| `--hostname` | string  | `127.0.0.1` | 主机名（`0.0.0.0` 允许外部访问） |
| `--mdns`     | boolean | `false`     | 启用 mDNS 广播                   |

## 核心命令

### run

运行 OpenCode 并发送消息。

#### 基本用法

```bash
opencode run [message..]
```

#### 选项

| 选项         | 简写 | 类型     | 描述                                 |
| ------------ | ---- | -------- | ------------------------------------ |
| `--command`  | -    | string   | 要执行的命令，使用 message 作为参数  |
| `--continue` | `-c` | boolean  | 继续上一个会话                       |
| `--session`  | `-s` | string   | 要继续的会话 ID                      |
| `--share`    | -    | boolean  | 分享会话                             |
| `--model`    | `-m` | string   | 使用的模型（格式：`provider/model`） |
| `--agent`    | -    | string   | 使用的代理                           |
| `--format`   | -    | string   | 输出格式：`default` 或 `json`        |
| `--file`     | `-f` | string[] | 要附加到消息的文件                   |
| `--title`    | -    | string   | 会话标题                             |
| `--attach`   | -    | string   | 附加到正在运行的服务器               |
| `--port`     | -    | number   | 本地服务器端口                       |
| `--variant`  | -    | string   | 模型变体（提供商特定的推理级别）     |

#### 示例

```bash
# 发送简单消息
opencode run "帮我添加一个新功能"

# 继续上一个会话
opencode run --continue

# 使用特定模型和代理
opencode run -m anthropic/claude-3-5-sonnet-20241022 --agent plan "分析这个代码库"

# 附加文件
opencode run -f README.md -f package.json "阅读这些文件"

# 使用 JSON 格式输出
opencode run --format json "测试"

# 附加到远程服务器
opencode run --attach http://localhost:4096 "远程工作"

# 指定会话标题
opencode run --title "添加认证功能" "实现 OAuth 登录"
```

### serve

启动无头 OpenCode 服务器。

#### 基本用法

```bash
opencode serve
```

#### 选项

| 选项         | 简写 | 类型   | 默认        | 描述       |
| ------------ | ---- | ------ | ----------- | ---------- |
| `--port`     | -    | number | `0`         | 服务器端口 |
| `--hostname` | -    | string | `127.0.0.1` | 主机名     |

#### 示例

```bash
# 使用默认端口启动
opencode serve

# 在特定端口启动
opencode serve --port 4096

# 允许网络访问
opencode serve --hostname 0.0.0.0 --port 4096

# 设置环境变量保护服务器
export OPENCODE_SERVER_PASSWORD=your-secret-password
opencode serve
```

### auth

管理 AI 提供商凭证。

#### 基本用法

```bash
opencode auth <command>
```

#### 子命令

##### login

登录到提供商。

```bash
opencode auth login [url]
```

**参数：**

- `url`（可选）：opencode auth provider URL 或 well-known 端点

**示例：**

```bash
# 交互式登录（选择提供商）
opencode auth login

# 使用自定义提供商
opencode auth login my-custom-provider

# 使用 well-known 端点
opencode auth login https://example.com/opencode
```

##### logout

从提供商登出。

```bash
opencode auth logout
```

**示例：**

```bash
opencode auth logout
# 选择要登出的提供商
```

##### list (ls)

列出所有已配置的凭证。

```bash
opencode auth list
```

**输出示例：**

```
Credentials ~/.opencode/auth.json

Anthropic            api
OpenAI               oauth
Google               api

3 credentials

Environment

OpenAI              OPENAI_API_KEY
```

#### 示例

```bash
# 列出所有凭证
opencode auth list

# 登录到 OpenCode
opencode auth login
# 选择 "opencode" 提供商

# 登录到 Anthropic
opencode auth login
# 选择 "anthropic" 提供商

# 登出
opencode auth logout
# 选择要删除的凭证
```

### agent

管理和创建代理。

#### 基本用法

```bash
opencode agent <command>
```

#### 子命令

##### create

创建新代理。

```bash
opencode agent create
```

**选项：**
| 选项 | 简写 | 类型 | 描述 |
|------|--------|------|------|
| `--path` | - | string | 生成代理文件的目录路径 |
| `--description` | - | string | 代理的功能描述 |
| `--mode` | - | string | 代理模式：`all`、`primary`、`subagent` |
| `--tools` | - | string | 启用的工具列表（逗号分隔） |
| `--model` | `-m` | string | 使用的模型（格式：`provider/model`） |

**示例：**

```bash
# 交互式创建代理
opencode agent create

# 非交互式创建代理
opencode agent create \
  --path ~/.opencode \
  --description "Review pull requests for code quality" \
  --mode primary \
  --tools read,edit,grep \
  --model anthropic/claude-3-5-sonnet-20241022
```

##### list

列出所有可用的代理。

```bash
opencode agent list
```

**输出示例：**

```
build (primary)
  {"bash":"ask","edit":"allow",...}

plan (primary)
  {"bash":"deny","edit":"ask",...}

my-reviewer (primary)
  {"bash":"allow","edit":"allow",...}
```

#### 示例

```bash
# 列出所有代理
opencode agent list

# 创建新的主代理
opencode agent create
# 输入描述后，代理将被自动生成

# 指定位置创建代理
opencode agent create --path .opencode/agent --description "文档编写助手"
```

### mcp

管理 MCP（Model Context Protocol）服务器。

#### 基本用法

```bash
opencode mcp <command>
```

#### 子命令

##### add

添加 MCP 服务器。

```bash
opencode mcp add
```

**交互式流程：**

1. 选择配置位置（当前项目或全局）
2. 输入服务器名称
3. 选择服务器类型（`local` 或 `remote`）
4. 根据类型输入命令或 URL
5. 对于 remote，可选择配置 OAuth

**示例：**

```bash
# 添加本地 MCP 服务器
opencode mcp add
# 选择 "Local"
# 输入命令：opencode x @modelcontextprotocol/server-filesystem

# 添加远程 MCP 服务器
opencode mcp add
# 选择 "Remote"
# 输入 URL：https://example.com/mcp
# 选择是否需要 OAuth
```

##### list (ls)

列出 MCP 服务器及其状态。

```bash
opencode mcp list
```

**状态图标：**

- `✓` - 已连接
- `⚠` - 需要认证或已过期
- `✗` - 连接失败
- `○` - 未初始化或已禁用

**输出示例：**

```
MCP Servers

✓ filesystem connected
    opencode x @modelcontextprotocol/server-filesystem

⚠ my-remote needs authentication (OAuth)
    https://example.com/mcp

✗ database failed
    https://db.example.com/mcp

3 server(s)
```

##### auth

对 OAuth 启用的 MCP 服务器进行认证。

```bash
opencode mcp auth [name]
```

**参数：**

- `name`（可选）：MCP 服务器名称

**子命令：**

- `list` / `ls`：列出 OAuth 能力的服务器及其认证状态

**示例：**

```bash
# 列出 OAuth 服务器
opencode mcp auth list

# 认证特定服务器
opencode mcp auth my-remote

# 认证所有服务器（交互式）
opencode mcp auth
```

##### logout

移除 MCP 服务器的 OAuth 凭证。

```bash
opencode mcp logout [name]
```

**参数：**

- `name`（可选）：MCP 服务器名称

**示例：**

```bash
# 移除特定服务器的凭证
opencode mcp logout my-remote

# 交互式选择服务器
opencode mcp logout
```

##### debug

调试 MCP 服务器的 OAuth 连接。

```bash
opencode mcp debug <name>
```

**参数：**

- `name`：MCP 服务器名称

**输出示例：**

```
MCP OAuth Debug

Server: my-remote
URL: https://example.com/mcp
Auth status: ✓ authenticated
  Access token: sk-ant-xxxxx...
  Expires: 2025-01-23T12:00:00.000Z (EXPIRED)
  Refresh token: present

Testing connection...
HTTP response: 200 OK
Server responded successfully (no auth required or already authenticated)
Server info: {"name":"Example MCP","version":"1.0.0"}

Debug complete
```

#### 示例

```bash
# 列出所有 MCP 服务器
opencode mcp list

# 添加新的 MCP 服务器
opencode mcp add

# 认证 MCP 服务器
opencode mcp auth my-remote

# 调试连接
opencode mcp debug my-remote

# 登出
opencode mcp logout my-remote
```

### github

管理 GitHub 代理。

#### 基本用法

```bash
opencode github <command>
```

#### 子命令

##### install

安装 GitHub 代理。

```bash
opencode github install
```

**安装流程：**

1. 检测 Git 仓库
2. 安装 GitHub App
3. 选择 AI 提供商
4. 选择模型
5. 添加工作流文件到 `.github/workflows/opencode.yml`

**示例：**

```bash
# 安装 GitHub 代理
opencode github install
# 按照提示选择提供商和模型
# 提交并推送工作流文件
```

**生成的工作流文件：**

```yaml
name: opencode

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  opencode:
    if: |
      contains(github.event.comment.body, ' /oc') ||
      startsWith(github.event.comment.body, '/oc') ||
      contains(github.event.comment.body, ' /opencode') ||
      startsWith(github.event.comment.body, '/opencode')
    runs-on: ubuntu-latest
    permissions:
      id-token: write
      contents: read
      pull-requests: read
      issues: read
    steps:
      - name: Checkout repository
        uses: actions/checkout@v6
        with:
          persist-credentials: false

      - name: Run opencode
        uses: anomalyco/opencode/github@latest
        with:
          model: opencode/claude-3-5-sonnet-20250514
```

##### run

运行 GitHub 代理（用于调试）。

```bash
opencode github run
```

**选项：**
| 选项 | 简写 | 类型 | 描述 |
|------|--------|------|------|
| `--event` | - | string | 要运行代理的 GitHub 模拟事件 |
| `--token` | - | string | GitHub 个人访问令牌 |

**示例：**

```bash
# 使用模拟事件运行（调试）
opencode github run --event @event.json

# 使用个人令牌运行
opencode github run --token github_pat_xxxxxxxxx
```

### pr

获取并检出 GitHub PR 分支，然后运行 OpenCode。

#### 基本用法

```bash
opencode pr <number>
```

#### 参数

| 参数     | 类型   | 描述             |
| -------- | ------ | ---------------- |
| `number` | number | 要检出的 PR 编号 |

#### 功能

1. 检出 PR 分支（使用 `gh pr checkout`）
2. 自动检测 fork 并配置远程
3. 在 PR 描述中检测 OpenCode 会话链接
4. 如果找到会话，自动导入
5. 启动 OpenCode TUI

#### 示例

```bash
# 检出 PR #123
opencode pr 123

# 流程输出示例：
# Fetching and checking out PR #123...
# Added fork remote: user-fork
# Successfully checked out PR #123 as branch 'pr/123'
# Starting opencode...
```

### stats

显示 token 使用和成本统计信息。

#### 基本用法

```bash
opencode stats
```

#### 选项

| 选项        | 简写 | 类型           | 描述                                             |
| ----------- | ---- | -------------- | ------------------------------------------------ |
| `--days`    | -    | number         | 显示最近 N 天的统计（默认：所有时间）            |
| `--tools`   | -    | number         | 显示的工具数量（默认：所有）                     |
| `--models`  | -    | number/boolean | 显示模型统计（数字显示前 N 个，true 显示所有）   |
| `--project` | -    | string         | 按项目过滤（默认：所有项目，空字符串：当前项目） |

#### 输出示例

```
┌────────────────────────────────────────────────────────┐
│                       OVERVIEW                         │
├────────────────────────────────────────────────────────┤
│Sessions            25                              │
│Messages           142                              │
│Days               7                                │
└────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────┐
```

### upgrade

将 OpenCode 升级到最新版本或特定版本。

#### 基本用法

```bash
opencode upgrade [target]
```

#### 参数

| 参数     | 类型   | 描述                                           |
| -------- | ------ | ---------------------------------------------- |
| `target` | string | 要升级到的版本，例如 `'0.1.48'` 或 `'v0.1.48'` |

#### 选项

| 选项       | 简写 | 类型   | 描述                                                             |
| ---------- | ---- | ------ | ---------------------------------------------------------------- |
| `--method` | `-m` | string | 安装方法：`curl`、`npm`、`pnpm`、`bun`、`brew`、`choco`、`scoop` |

#### 示例

```bash
# 升级到最新版本
opencode upgrade

# 升级到特定版本
opencode upgrade 0.1.50

# 使用特定方法升级
opencode upgrade --method brew

# 升级到带 v 前缀的版本
opencode upgrade v0.1.50
```

### acp

启动 ACP（Agent Client Protocol）服务器。

#### 基本用法

```bash
opencode acp
```

#### 选项

| 选项         | 简写 | 类型   | 默认          | 描述     |
| ------------ | ---- | ------ | ------------- | -------- |
| `--cwd`      | -    | string | process.cwd() | 工作目录 |
| `--port`     | -    | number | `0`           | 端口号   |
| `--hostname` | -    | string | `127.0.0.1`   | 主机名   |

#### 用途

ACP 允许外部工具通过标准化协议与 OpenCode 通信。

#### 示例

```bash
# 在当前目录启动 ACP 服务器
opencode acp

# 在特定目录启动
opencode acp --cwd /path/to/project

# 使用特定端口
opencode acp --port 4096
```

## TUI 命令

### 默认命令（$0）

启动 OpenCode TUI（不带子命令时的默认行为）。

#### 基本用法

```bash
opencode [project]
# 或
opencode
```

#### 选项

| 选项         | 简写 | 类型    | 描述                                 |
| ------------ | ---- | ------- | ------------------------------------ |
| `project`    | -    | string  | 启动 OpenCode 的路径                 |
| `--model`    | `-m` | string  | 使用的模型（格式：`provider/model`） |
| `--continue` | `-c` | boolean | 继续上一个会话                       |
| `--session`  | `-s` | string  | 要继续的会话 ID                      |
| `--prompt`   | -    | string  | 使用的提示词                         |
| `--agent`    | -    | string  | 使用的代理                           |
| `--port`     | -    | number  | 服务器端口                           |
| `--hostname` | -    | string  | 主机名                               |

#### 示例

```bash
# 在当前目录启动 TUI
opencode

# 在特定项目启动
opencode /path/to/project

# 使用特定模型和代理
opencode -m anthropic/claude-3-5-sonnet-20241022 --agent plan

# 继续上一个会话
opencode --continue

# 使用初始提示词启动
opencode --prompt "审查这个 PR"

# 附加到远程服务器
opencode --attach http://localhost:4096
```

### attach

附加到正在运行的 OpenCode 服务器。

#### 基本用法

```bash
opencode attach <url>
```

#### 参数

| 参数  | 类型   | 描述                                     |
| ----- | ------ | ---------------------------------------- |
| `url` | string | 服务器 URL，例如 `http://localhost:4096` |

#### 选项

| 选项        | 简写 | 类型   | 描述            |
| ----------- | ---- | ------ | --------------- |
| `--dir`     | -    | string | 运行的目录      |
| `--session` | `-s` | string | 要继续的会话 ID |

#### 示例

```bash
# 附加到本地服务器
opencode attach http://localhost:4096

# 在特定目录附加
opencode attach http://localhost:4096 --dir /path/to/project

# 继续特定会话
opencode attach http://localhost:4096 --session ses_abc123
```

## 常用场景

### 场景 1：快速开始开发

```bash
# 在项目目录启动 OpenCode
cd /path/to/my-project
opencode

# 发送第一个消息
# 在 TUI 中输入：帮我理解这个项目的结构
```

### 场景 2：使用特定代理和模型

```bash
# 使用 plan 代理（只读）进行分析
opencode run -m anthropic/claude-3-5-sonnet-20241022 --agent plan "分析代码质量"

# 使用默认 build 代理进行开发
opencode run -m opencode/claude-3-5-sonnet-20250514 --agent build "添加用户认证"
```

### 场景 3：处理 PR

```bash
# 检出 PR 并开始工作
opencode pr 123

# 或使用 TUI 附加到 PR 上下文
opencode attach http://localhost:4096 --session ses_from_pr
```

### 场景 4：共享和导入会话

```bash
# 导出会话
opencode export ses_abc123 > my-session.json

# 导入到另一个项目
cd /path/to/other-project
opencode import my-session.json

# 从共享链接导入
opencode import https://opencode.ai/share/abc123
```

### 场景 5：服务器部署

```bash
# 启动无头服务器
export OPENCODE_SERVER_PASSWORD=your-secret
opencode serve --hostname 0.0.0.0 --port 4096

# 从其他机器附加
opencode attach http://server-ip:4096
```

### 场景 6：设置 MCP 服务器

```bash
# 添加文件系统 MCP
opencode mcp add
# 名称：filesystem
# 类型：Local
# 命令：opencode x @modelcontextprotocol/server-filesystem

# 添加远程 MCP
opencode mcp add
# 名称：my-api
# 类型：Remote
# URL：https://api.example.com/mcp
# OAuth：Yes

# 验证连接
opencode mcp list
```

### 场景 7：查看使用统计

```bash
# 查看所有统计
opencode stats

# 查看本周使用情况
opencode stats --days 7

# 查看特定项目
opencode stats --project my-project

# 监控成本
opencode stats --days 30 | grep "Total Cost"
```

### 场景 8：调试问题

```bash
# 查看全局路径
opencode debug paths

# 检查配置
opencode debug config

# 创建快照用于分析
opencode debug snapshot
```

## 高级技巧

### 管道输入

```bash
# 从管道读取消息
echo "帮我重构这个函数" | opencode run

# 从文件读取
cat prompt.txt | opencode run
```

### 环境变量

| 变量                       | 描述                             |
| -------------------------- | -------------------------------- |
| `OPENCODE_SERVER_PASSWORD` | 服务器密码                       |
| `OPENCODE_AUTO_SHARE`      | 自动分享会话                     |
| `BUN_OPTIONS`              | Bun 运行时选项（如 `--inspect`） |

### 配置文件

OpenCode 从以下位置读取配置（按优先级）：

1. `.opencode/opencode.json`（项目）
2. `.opencode/opencode.jsonc`（项目）
3. `~/.opencode/opencode.json`（全局）
4. `~/.opencode/opencode.jsonc`（全局）

### 日志配置

```bash
# 启用调试日志
opencode --print-logs --log-level DEBUG run "测试消息"

# 查看日志文件位置
opencode debug paths | grep "data"
```

## 故障排除

### 命令未找到

```bash
# 确保在 PATH 中
which opencode

# 查看可用命令
opencode --help
```

### 认证问题

```bash
# 列出当前凭证
opencode auth list

# 清除并重新认证
opencode auth logout
opencode auth login
```

### MCP 连接失败

```bash
# 检查 MCP 服务器状态
opencode mcp list

# 调试连接
opencode mcp debug <server-name>
```
