## 概述

`@opencode-ai/ui` 是 OpenCode 项目的共享 UI 组件库，专为 Web 应用和桌面应用提供一致的视觉设计和交互体验。该组件库基于 SolidJS 构建，使用 Kobalte 提供无障碍支持，并集成了 Tailwind CSS 进行样式管理。

### 主要特性

- **统一的设计语言**：确保所有 OpenCode 应用界面的一致性
- **无障碍优先**：基于 Kobalte 构建的原生 ARIA 支持
- **主题系统**：支持多种内置主题和自定义主题
- **响应式设计**：适配不同屏幕尺寸和设备
- **国际化支持**：内置 i18n 上下文
- **高性能**：优化的渲染和状态管理
- **类型安全**：完整的 TypeScript 类型定义

### 包信息

- **包名**：`@opencode-ai/ui`
- **版本**：1.1.31
- **位置**：`packages/ui/`
- **许可证**：MIT

## 组件设计原则

### 1. 无障碍优先

所有组件基于 **@kobalte/core** 构建，确保：

- 原生 ARIA 支持
- 键盘导航
- 屏幕阅读器兼容
- 焦点管理
- 语义化 HTML

**示例**：

```tsx
// ✅ 好的做法：使用 Kobalte 基础组件
import { Button as Kobalte } from "@kobalte/core/button"

export function Button(props: ButtonProps) {
  return <Kobalte {...props} />
}

// ❌ 避免：直接使用原生 HTML
export function Button(props: ButtonProps) {
  return <button {...props} />
}
```

### 2. 组合优于继承

组件通过子组件组合提供灵活性：

```tsx
<Dialog>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Title>Title</Dialog.Title>
    <Dialog.Description>Description</Dialog.Description>
    <Dialog.Close>Close</Dialog.Close>
  </Dialog.Content>
</Dialog>
```

### 3. 属性传递模式

使用 `splitProps` 分离自定义属性和原生属性：

```tsx
import { splitProps } from "solid-js"

export function Card(props: CardProps) {
  const [split, rest] = splitProps(props, ["variant", "class", "classList"])
  return (
    <div
      {...rest}
      data-component="card"
      data-variant={split.variant}
      classList={{
        ...(split.classList ?? {}),
        [split.class ?? ""]: !!split.class,
      }}
    >
      {props.children}
    </div>
  )
}
```

### 4. 样式属性化

使用 `data-*` 属性控制样式变体：

```tsx
// 组件
<div data-component="button" data-variant="primary" data-size="large">
  Button
</div>

// CSS
[data-component="button"][data-variant="primary"] {
  background: blue;
}
```

### 5. 可预测的 API

- 组件 Props 明确且类型安全
- 变体通过枚举限制
- 默认值合理

```tsx
interface ButtonProps {
  size?: "small" | "normal" | "large" // 明确的选项
  variant?: "primary" | "secondary" | "ghost"
}
```

### 6. 样式分离

每个组件都有配套的 CSS 文件：

```
components/
├── button.tsx
├── button.css
├── dialog.tsx
└── dialog.css
```

## 样式系统

### CSS 层架构

样式系统使用 **CSS Layers** 进行分层管理：

```css
@layer theme, base, components, utilities;

@import "./colors.css" layer(theme);
@import "./theme.css" layer(theme);

@import "./base.css" layer(base);

@import "./components/accordion.css" layer(components);
@import "./components/button.css" layer(components);
/* ... */

@import "./utilities.css" layer(utilities);
```

### 层级说明

| 层级           | 用途               | 优先级 |
| -------------- | ------------------ | ------ |
| **theme**      | CSS 变量、主题定义 | 低     |
| **base**       | 基础样式重置       | 中     |
| **components** | 组件样式           | 高     |
| **utilities**  | 工具类             | 最高   |

### Tailwind CSS 集成

项目使用 Tailwind CSS 进行样式管理：

**配置**：`packages/ui/tailwind.config.ts`

**使用方式**：

```tsx
// 在组件中使用 Tailwind 类
<div class="flex items-center gap-2 p-4">Content</div>
```

**生成样式**：

```bash
bun run --cwd packages/ui generate:tailwind
```

### CSS 变量系统

使用 CSS 变量实现主题化和动态样式：

```css
:root {
  --color-primary: oklch(0.7 0.15 250);
  --color-secondary: oklch(0.5 0.1 250);
  --font-sans: system-ui, sans-serif;

```

## 自定义 Hooks

### use-filtered-list

过滤和搜索列表的 Hook。

```tsx
import { useFilteredList } from "@opencode-ai/ui/hooks"

function SearchList({ items }: { items: string[] }) {
  const [filteredList, setFilter] = useFilteredList(items)

  return (
    <div>
      <input onInput={(e) => setFilter(e.target.value)} />
      <ul>
        {filteredList().map((item) => (
          <li key={item}>{item}</li>
        ))}
      </ul>
    </div>
  )
}
```

### create-auto-scroll

自动滚动到底部的 Hook。

```tsx
import { createAutoScroll } from "@opencode-ai/ui/hooks"

function Chat() {
  const [messages, setMessages] = createSignal([])
  const containerRef = createRef<HTMLDivElement>()
  const scroll = createAutoScroll(containerRef)

  createEffect(() => {
    scroll()
  })

  return <div ref={containerRef}>{messages()}</div>
}
```

## 无障碍支持

### Kobalte 基础

所有交互组件基于 **@kobalte/core**，提供：

- **ARIA 属性**：自动生成正确的 ARIA 属性
- **键盘导航**：Tab、Enter、Escape 等键支持
- **焦点管理**：焦点捕获、焦点移动
- **屏幕阅读器**：语义化标签和描述

### 无障碍最佳实践

#### 1. 语义化 HTML

```tsx
// ✅ 好的做法
import { Button } from "@opencode-ai/ui/button"

<Button>Click me</Button>

// ❌ 避免
<div onClick={handleClick} role="button">Click me</div>
```

#### 2. ARIA 标签

```tsx
<IconButton name="close" aria-label="Close dialog" />
```

#### 3. 焦点管理

```tsx
<Dialog.Content>
  <Dialog.Title>Dialog Title</Dialog.Title>
  {/* Dialog 自动管理焦点 */}
</Dialog.Content>
```

#### 4. 键盘支持

所有交互组件支持键盘操作：

- `Tab`：焦点导航
- `Enter` / `Space`：激活按钮/选择项
- `Escape`：关闭对话框/下拉菜单
- `Arrow` 键：在列表中导航

## 开发新组件

### 组件模板

创建新组件时，遵循以下结构：

```tsx
// packages/ui/src/components/my-component.tsx
import { splitProps } from "solid-js"
import type { ComponentProps, ParentProps } from "solid-js"

export interface MyComponentProps extends ComponentProps<"div"> {
  variant?: "normal" | "primary"
  // 自定义属性
}

export function MyComponent(props: ParentProps<MyComponentProps>) {
  const [split, rest] = splitProps(props, ["variant", "class", "classList", "children"])
  return (
    <div
      {...rest}
      data-component="my-component"
      data-variant={split.variant || "normal"}
      classList={{
        ...(split.classList ?? {}),
        [split.class ?? ""]: !!split.class,
      }}
    >
      {split.children}
    </div>
  )
}
```

### 样式文件

```css
/* packages/ui/src/components/my-component.css */
[data-component="my-component"] {
  /* 默认样式 */
}

[data-component="my-component"][data-variant="primary"] {
  /* 变体样式 */
}

[data-component="my-component"]:hover {
  /* 悬停状态 */
}

[data-component="my-component"]:focus-visible {
  /* 焦点状态 */
}
```

### 导出样式

在 `packages/ui/src/styles/index.css` 中添加导入：

```css
@import "../components/my-component.css" layer(components);
```

### 导出组件

确保组件可以通过包导出：

```tsx

{
  "exports": {
    "./my-component": "./src/components/my-component.tsx"
  }

```


## 最佳实践

### 1. 保持组件简单

```tsx
// ✅ 好的做法：职责单一
function Button(props: ButtonProps) {
  return <button {...props} />
}

// ❌ 避免：组件包含过多逻辑
function Button(props: ButtonProps) {
  const [isLoading, setIsLoading] = createSignal(false)
  const handleClick = async () => {
    setIsLoading(true)
    await props.onClick?.()
    setIsLoading(false)
  }
  // ... 复杂逻辑
}
```

### 2. 使用 TypeScript 严格模式

```tsx
// ✅ 明确的类型定义
interface Props {
  value: string
  onChange: (value: string) => void
}

// ❌ 避免使用 any
interface Props {
  value: any
  onChange: any
}
```

### 3. 可组合的子组件

```tsx
// ✅ 好的做法：可组合
<Dialog>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Title>Title</Dialog.Title>
  </Dialog.Content>
</Dialog>

// ❌ 避免：不灵活的配置
<Dialog
  trigger="Open"
  title="Title"
  content="Content"
/>
```

### 4. 性能优化

```tsx
// ✅ 使用 createMemo 和 createComputed
const filteredList = createMemo(() => list().filter((item) => item.value.includes(query())))

// ✅ 使用虚拟滚动（大列表）
import { List } from "@opencode-ai/ui/list"

;<List items={largeList()} estimateSize={() => 50}>
  {(item) => <div>{item}</div>}
</List>
```

### 5. 主题和样式

```tsx
// ✅ 使用主题变量
<div style={{ color: "var(--color-primary)" }} />

// ❌ 避免硬编码颜色
<div style={{ color: "#FF5733" }} />
```

### 6. 无障碍

```tsx
// ✅ 添加 ARIA 标签
<Button aria-label="Close dialog">
  <Icon name="x" />
</Button>

// ❌ 缺少无障碍支持
<div onClick={handleClose}>
  <Icon name="x" />
</div>
```

### 7. 代码组织

```
// ✅ 清晰的文件结构
components/
├── button.tsx
├── button.css
├── dialog.tsx
├── dialog.css
└── ...
```

### 8. 错误边界

```tsx
import { ErrorBoundary } from "solid-js"

;<ErrorBoundary fallback={(err) => <ErrorComponent error={err} />}>
  <MyComponent />
</ErrorBoundary>
```

### 9. 条件渲染

```tsx
// ✅ 使用 Show 组件
;<Show when={isLoggedIn()}>
  <UserProfile />
</Show>

// ❌ 避免：if 语句
if (isLoggedIn()) {
  return <UserProfile />
}
return <Login />
```

### 10. 事件处理

```tsx
// ✅ 明确的事件处理
function handleClick(event: MouseEvent) {
  event.preventDefault()
  // ...
}

// ❌ 不明确的
function handleClick() {
  // ...
}
```
