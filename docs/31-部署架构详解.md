## 概述

OpenCode 采用灵活的部署架构，支持多种部署方式以适应不同的使用场景和基础设施需求。从本地开发到生产环境部署，OpenCode 提供了全面的部署选项。

### 部署模式

| 部署方式       | 适用场景             | 优势               | 复杂度     |
| -------------- | -------------------- | ------------------ | ---------- |
| **本地部署**   | 个人开发、测试       | 简单快速、零配置   | ⭐         |
| **Docker**     | 容器化环境、团队协作 | 环境一致、易于管理 | ⭐⭐       |
| **服务器部署** | 专用服务器、VPS      | 完全控制、性能优化 | ⭐⭐⭐     |
| **云平台部署** | 生产环境、高可用     | 自动扩展、托管服务 | ⭐⭐⭐⭐   |
| **Kubernetes** | 企业级、大规模编排   | 高可用、自动恢复   | ⭐⭐⭐⭐⭐ |

### 架构特性

- **客户端-服务器架构**：OpenCode Core Server 运行在服务器端，多个客户端可连接
- **状态管理**：会话数据持久化存储，支持跨客户端同步
- **插件系统**：运行时加载插件，无需重新部署
- **多客户端支持**：TUI、Web、Desktop 等多种客户端类型

### 目录结构

OpenCode 遵循 XDG Base Directory Specification，数据存储位置如下：

```
~/.local/share/opencode/    # XDG_DATA_HOME
├── auth.json               # 认证凭证
├── config.json             # 用户配置
├── log/                    # 日志文件
├── plugin/                 # 插件缓存
├── session/                # 会话数据
└── model/                  # 模型缓存

~/.cache/opencode/           # XDG_CACHE_HOME
├── cache/                  # 临时缓存
└── lsp/                    # LSP 服务器缓存

~/.config/opencode/          # XDG_CONFIG_HOME
└── opencode.json           # 全局配置（可选）
```

### 环境变量

```bash
# 安装路径优先级
export OPENCODE_INSTALL_DIR=/usr/local/bin
export XDG_BIN_DIR=$HOME/.local/bin

# 禁用功能
export OPENCODE_DISABLE_MODELS_FETCH=true      # 禁用自动获取模型列表
export OPENCODE_DISABLE_SHARE=true             # 禁用分享功能
export OPENCODE_DISABLE_LSP_DOWNLOAD=true      # 禁用自动下载 LSP
export OPENCODE_DISABLE_DEFAULT_PLUGINS=true   # 禁用默认插件

# 开发选项
export OPENCODE_EXPERIMENTAL_DISABLE_FILEWATCHER=true  # 禁用文件监控

# 自定义数据目录
export OPENCODE_TEST_HOME=/tmp/opencode-test
export XDG_DATA_HOME=/tmp/opencode-data
export XDG_CACHE_HOME=/tmp/opencode-cache
export XDG_CONFIG_HOME=/tmp/opencode-config
export XDG_STATE_HOME=/tmp/opencode-state

# 服务器模式
export OPENCODE_CLIENT=app  # 指定客户端类型
```

## Docker 部署

### Dockerfile 分析

OpenCode 提供了优化的 Dockerfile 用于容器化部署：

```dockerfile
FROM alpine AS base

# 禁用运行时转译器缓存（容器中无用）
ARG BUN_RUNTIME_TRANSPILER_CACHE_PATH=0
ENV BUN_RUNTIME_TRANSPILER_CACHE_PATH=${BUN_RUNTIME_TRANSPILER_CACHE_PATH}
RUN apk add libgcc libstdc++ ripgrep

FROM base AS build-amd64
COPY dist/opencode-linux-x64-baseline-musl/bin/opencode /usr/local/bin/opencode

FROM base AS build-arm64
COPY dist/opencode-linux-arm64-musl/bin/opencode /usr/local/bin/opencode

ARG TARGETARCH
FROM build-${TARGETARCH}
RUN opencode --version
ENTRYPOINT ["opencode"]
```

### 构建 Docker 镜像

```bash
# 克隆仓库
git clone https://github.com/anomalyco/opencode.git
cd opencode

# 构建二进制文件
bun install
bun run build:binary

# 构建 Docker 镜像（AMD64）
docker build --build-arg TARGETARCH=amd64 -t opencode:latest .

# 构建 Docker 镜像（ARM64）
docker build --build-arg TARGETARCH=arm64 -t opencode:latest-arm64 .
```

### 运行 Docker 容器

```bash
# 基础运行
docker run -it --rm opencode:latest

# 挂载数据目录（持久化）
docker run -it --rm \
  -v opencode-data:/local/share/opencode \
  -v opencode-cache:/cache/opencode \
  -v opencode-config:/config/opencode \
  -v $(pwd):/workspace \
  -w /workspace \
  opencode:latest

# 运行服务器模式
docker run -d --name opencode-server \
  -p 4096:4096 \
  -v opencode-data:/local/share/opencode \
  opencode:latest \
  opencode serve --port 4096 --hostname 0.0.0.0

# 环境变量配置
docker run -it --rm \
  -e OPENCODE_DISABLE_MODELS_FETCH=true \
  -e OPENCODE_DISABLE_SHARE=true \
  -v $(pwd):/workspace \
  -w /workspace \
  opencode:latest
```

### Docker Compose

创建 `docker-compose.yml`：

```yaml
version: "3.8"

services:
  opencode-server:
    image: opencode:latest
    container_name: opencode-server
    restart: unless-stopped
    ports:
      - "4096:4096"
    volumes:
      - opencode-data:/local/share/opencode
      - opencode-cache:/cache/opencode
      - opencode-config:/config/opencode
      - ./workspace:/workspace
    working_dir: /workspace
    environment:
      - OPENCODE_DISABLE_MODELS_FETCH=true
      - OPENCODE_DISABLE_SHARE=true
      - OPENCODE_EXPERIMENTAL_DISABLE_FILEWATCHER=false
    command: >
      opencode serve
        --port 4096
        --hostname 0.0.0.0
        --log-level INFO

volumes:
  opencode-data:
    driver: local
  opencode-cache:
    driver: local
  opencode-config:
    driver: local
```

运行：

```bash
# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

### Docker 最佳实践

1. **多架构支持**

```bash
# 使用 buildx 构建多架构镜像
docker buildx build --platform linux/amd64,linux/arm64 -t opencode:latest .

# 推送到 registry
docker push opencode:latest
```

2. **镜像优化**

```dockerfile
# 使用多阶段构建减少镜像大小
FROM alpine:3.20 AS builder
RUN apk add --no-cache git curl
# ... 构建步骤 ...

FROM alpine:3.20
RUN apk add --no-cache libgcc libstdc++ ripgrep
COPY --from=builder /usr/local/bin/opencode /usr/local/bin/opencode
RUN opencode --version
ENTRYPOINT ["opencode"]
```

3. **安全实践**

```bash
# 使用非 root 用户运行
docker run -it --user $(id -u):$(id -g) opencode:latest

# 只读文件系统
docker run -it --read-only --tmpfs /tmp opencode:latest

# 限制资源
docker run -it \
  --memory="2g" \
  --cpus="2" \
  opencode:latest
```

## 服务器部署

### 系统要求

**最低要求**：

- CPU: 2 核心
- 内存: 4GB RAM
- 磁盘: 10GB 可用空间
- 操作系统: Linux (Ubuntu 20.04+, Debian 11+, CentOS 8+)

**推荐配置**：

- CPU: 4+ 核心
- 内存: 8GB+ RAM
- 磁盘: 50GB+ SSD
- 操作系统: Ubuntu 22.04 LTS

### 安装步骤

#### 1. 更新系统

```bash
sudo apt update && sudo apt upgrade -y

# 安装必要的依赖
sudo apt install -y curl git vim htop build-essential
```

#### 2. 安装 OpenCode

```bash
# 使用安装脚本
curl -fsSL https://opencode.ai/install | bash

# 验证安装
opencode --version
```

#### 3. 创建专用用户

```bash
# 创建 opencode 用户
sudo useradd -r -s /bin/false opencode

# 创建数据目录
sudo mkdir -p /var/lib/opencode
sudo mkdir -p /var/log/opencode
sudo mkdir -p /etc/opencode

# 设置权限
sudo chown -R opencode:opencode /var/lib/opencode
sudo chown -R opencode:opencode /var/log/opencode
sudo chown -R opencode:opencode /etc/opencode
```

#### 4. 配置服务（Systemd）

创建 `/etc/systemd/system/opencode.service`：

```ini
[Unit]
Description=OpenCode Server
After=network.target
Wants=network.target

[Service]
Type=simple
User=opencode
Group=opencode
WorkingDirectory=/home/opencode
Environment="OPENCODE_DISABLE_MODELS_FETCH=true"
Environment="OPENCODE_DISABLE_SHARE=true"
ExecStart=/usr/local/bin/opencode serve \
  --port 4096 \
  --hostname 0.0.0.0 \
  --log-level INFO
Restart=always
RestartSec=10

# 资源限制
LimitNOFILE=65536
MemoryLimit=4G
CPUQuota=200%

# 安全设置
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/var/lib/opencode /var/log/opencode /etc/opencode

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启动服务
sudo systemctl start opencode

# 设置开机自启
sudo systemctl enable opencode

# 查看状态
sudo systemctl status opencode

# 查看日志
sudo journalctl -u opencode -f
```

#### 5. 配置 Nginx 反向代理

```nginx
upstream opencode_backend {
    server 127.0.0.1:4096;
    keepalive 64;
}

server {
    listen 80;
    listen [::]:80;
    server_name opencode.example.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name opencode.example.com;

    # SSL 证书
    ssl_certificate /etc/letsencrypt/live/opencode.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/opencode.example.com/privkey.pem;

    # SSL 配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers off;

    # 代理配置
    location / {
        proxy_pass http://opencode_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 300s;

        # 缓冲设置
        proxy_buffering off;
        proxy_request_buffering off;
    }

    # WebSocket 支持
    location /ws {
        proxy_pass http://opencode_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

获取 SSL 证书：

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d opencode.example.com

# 自动续期
sudo certbot renew --dry-run
```

## 云平台部署

### Cloudflare Workers (SST)

OpenCode 使用 SST (Serverless Stack) 部署到 Cloudflare Workers，这是主要的生产部署方式。

#### 配置文件

**sst.config.ts**：

```typescript
/// <reference path="./.sst/platform/config.d.ts" />

export default $config({
  app(input) {
    return {
      name: "opencode",
      removal: input?.stage === "production" ? "retain" : "remove",
      protect: ["production"].includes(input?.stage),
      home: "cloudflare",
      providers: {
        stripe: {
          apiKey: process.env.STRIPE_SECRET_KEY!,
        },
        planetscale: "0.4.1",
      },
    }
  },
  async run() {
    await import("./infra/app.js")
    await import("./infra/console.js")
    await import("./infra/enterprise.js")
  },
})
```

#### 基础设施定义

**infra/app.ts**：

```typescript
import { domain } from "./stage"

// Secrets
const GITHUB_APP_ID = new sst.Secret("GITHUB_APP_ID")
const GITHUB_APP_PRIVATE_KEY = new sst.Secret("GITHUB_APP_PRIVATE_KEY")
const EMAILOCTOPUS_API_KEY = new sst.Secret("EMAILOCTOPUS_API_KEY")
const ADMIN_SECRET = new sst.Secret("ADMIN_SECRET")
const DISCORD_SUPPORT_BOT_TOKEN = new sst.Secret("DISCORD_SUPPORT_BOT_TOKEN")
const DISCORD_SUPPORT_CHANNEL_ID = new sst.Secret("DISCORD_SUPPORT_CHANNEL_ID")
const FEISHU_APP_ID = new sst.Secret("FEISHU_APP_ID")
const FEISHU_APP_SECRET = new sst.Secret("FEISHU_APP_SECRET")

// Storage
const bucket = new sst.cloudflare.Bucket("Bucket")

// API Worker
export const api = new sst.cloudflare.Worker("Api", {
  domain: `api.${domain}`,
  handler: "packages/function/src/api.ts",
  environment: {
    WEB_DOMAIN: domain,
  },
  url: true,
  link: [
    bucket,
    GITHUB_APP_ID,
    GITHUB_APP_PRIVATE_KEY,
    ADMIN_SECRET,
    DISCORD_SUPPORT_BOT_TOKEN,
    DISCORD_SUPPORT_CHANNEL_ID,
    FEISHU_APP_ID,
    FEISHU_APP_SECRET,
  ],
  transform: {
    worker: (args) => {
      args.logpush = true // 启用日志推送
      args.bindings = $resolve(args.bindings).apply((bindings) => [
        ...bindings,
        {
          name: "SYNC_SERVER",
          type: "durable_object_namespace",
          className: "SyncServer",
        },
      ])
      args.migrations = {
        oldTag: $app.stage === "production" || $app.stage === "thdxr" ? "" : "v1",
        newTag: $app.stage === "production" || $app.stage === "thdxr" ? "" : "v1",
      }
    },
  },
})

// Web Docs (Astro)
new sst.cloudflare.x.Astro("Web", {
  domain: "docs." + domain,
  path: "packages/web",
  environment: {
    SST_STAGE: $app.stage,
    VITE_API_URL: api.url.apply((url) => url!),
  },
})

// Web App (Static Site)
new sst.cloudflare.StaticSite("WebApp", {
  domain: "app." + domain,
  path: "packages/app",
  build: {
    command: "bun turbo build",
    output: "./dist",
  },
})
```

## Kubernetes 部署

OpenCode 可以部署到 Kubernetes 集群，以下是一个完整的示例配置。

### Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: opencode
  namespace: opencode
  labels:
    app: opencode
spec:
  replicas: 2
  selector:
    matchLabels:
      app: opencode
  template:
    metadata:
      labels:
        app: opencode
        version: v1
    spec:
      containers:
        - name: opencode
          image: opencode:latest
          imagePullPolicy: Always
          ports:
            - name: http
              containerPort: 4096
              protocol: TCP

          env:
            - name: OPENCODE_DISABLE_MODELS_FETCH
              value: "true"
            - name: OPENCODE_DISABLE_SHARE
              value: "true"
            - name: OPENCODE_LOG_LEVEL
              value: "INFO"

          resources:
            requests:
              memory: "512Mi"
              cpu: "500m"
            limits:
              memory: "2Gi"
              cpu: "2000m"

          livenessProbe:
            httpGet:
              path: /health
              port: http
            initialDelaySeconds: 30
            periodSeconds: 10
            timeoutSeconds: 5
            failureThreshold: 3

          readinessProbe:
            httpGet:
              path: /ready
              port: http
            initialDelaySeconds: 10
            periodSeconds: 5
            timeoutSeconds: 3
            failureThreshold: 3

          volumeMounts:
            - name: data
              mountPath: /local/share/opencode
            - name: cache
              mountPath: /cache/opencode

      volumes:
        - name: data
          persistentVolumeClaim:
            claimName: opencode-data-pvc
        - name: cache
```

### 配置管理

1. **使用环境变量而非硬编码**

```bash
# 好
export ANTHROPIC_API_KEY=sk-ant-...
opencode serve

# 不好
opencode serve --api-key sk-ant-...
```

2. **敏感信息使用 Secrets**

```typescript
// 使用 SST Secrets
const API_KEY = new sst.Secret("API_KEY")

// 不要使用环境变量
// const API_KEY = process.env.API_KEY  // 不安全
```

3. **版本化配置**

```bash
# 使用 Git 跟踪配置文件模板
git add opencode.json.template

# 不跟踪敏感配置
echo "opencode.json" >> .gitignore
```

## 故障排查

### 常见问题

#### 问题 1: 端口已被占用

```bash
# 查找占用端口的进程
lsof -i :4096

# 杀死进程
kill -9 <PID>

# 或使用其他端口
opencode serve --port 4097
```

#### 问题 2: 权限错误

```bash
# 修复文件权限
sudo chown -R $USER:$USER ~/.local/share/opencode
sudo chmod -R 755 ~/.local/share/opencode

# Docker 挂载权限
docker run -it --user $(id -u):$(id -g) ...
```

#### 问题 3: 内存不足

```bash
# 增加交换空间
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# 永久生效
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

#### 问题 4: 连接超时

```bash
# 检查防火墙
sudo ufw status

# 检查服务状态
sudo systemctl status opencode

# 检查端口监听
ss -tulnp | grep 4096
```

#### 问题 5: 日志过多

```bash
# 清理旧日志
find ~/.local/share/opencode/log -name "*.log" -mtime +7 -delete

# 配置日志级别
opencode serve --log-level WARN
```

### 调试技巧

```bash
# 启用详细日志
opencode serve --log-level DEBUG --print-logs

# 检查配置
opencode config show

# 验证认证
opencode auth list

# 测试健康端点
curl http://localhost:4096/global/health

# Docker 日志
docker logs -f opencode-server

# Kubernetes 日志
kubectl logs -f -n opencode deployment/opencode
```
