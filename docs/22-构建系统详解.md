## 概述

OpenCode 使用多层构建系统来支持不同平台的开发和部署需求：

- **核心包 (packages/opencode)**：使用 Bun 的原生 `Bun.build()` API
- **Web 应用 (packages/app)**：使用 Vite + esbuild
- **桌面应用 (packages/desktop)**：使用 Vite + Tauri
- **Monorepo 管理**：使用 Turborepo 进行任务编排

## Bun 构建流程

### Bun.build() API

OpenCode 使用 Bun 的原生构建 API 来打包核心代码：

```typescript
// packages/opencode/script/build.ts
await Bun.build({
  conditions: ["browser"],
  tsconfig: "./tsconfig.json",
  plugins: [solidPlugin],
  sourcemap: "external",
  compile: {
    autoloadBunfig: false,
    autoloadDotenv: false,
    autoloadTsconfig: true,
    autoloadPackageJson: true,
    target: name.replace(pkg.name, "bun") as any,
    outfile: `dist/${name}/bin/opencode`,
    execArgv: ["--user-agent=opencode/${version}", "--use-system-ca", "--"],
    windows: {},
  },
  entrypoints: ["./src/index.ts", parserWorker, workerPath],
  define: {
    OPENCODE_VERSION: `'${version}'`,
    OTUI_TREE_SITTER_WORKER_PATH: bunfsRoot + workerRelativePath,
    OPENCODE_WORKER_PATH: workerPath,
    OPENCODE_CHANNEL: `'${channel}'`,
    OPENCODE_LIBC: item.os === "linux" ? `'${item.abi ?? "glibc"}'` : "",
  },
})
```

### 构建目标

OpenCode 为多个平台和架构构建二进制文件：

| 平台    | 架构  | ABI   | 输出文件名                    |
| ------- | ----- | ----- | ----------------------------- |
| Linux   | arm64 | glibc | opencode-linux-arm64          |
| Linux   | x64   | glibc | opencode-linux-x64            |
| Linux   | x64   | glibc | opencode-linux-x64-baseline   |
| Linux   | arm64 | musl  | opencode-linux-arm64-musl     |
| Linux   | x64   | musl  | opencode-linux-x64-musl       |
| macOS   | arm64 | -     | opencode-darwin-arm64         |
| macOS   | x64   | -     | opencode-darwin-x64           |
| macOS   | x64   | -     | opencode-darwin-x64-baseline  |
| Windows | x64   | -     | opencode-windows-x64          |
| Windows | x64   | -     | opencode-windows-x64-baseline |

### 构建命令

```bash
# 构建当前平台（默认）
bun run build

# 构建特定平台
bun run build --single

# 构建所有平台
bun run build

# 构建时不安装依赖（使用已缓存的）
bun run build --skip-install

# 构建基准版本（无 AVX2）
bun run build --baseline
```

### 构建产物

构建产物输出到 `dist/` 目录：

```
dist/
├── opencode-linux-arm64/
│   ├── bin/
│   │   └── opencode
│   └── package.json
├── opencode-darwin-arm64/
│   ├── bin/
│   │   └── opencode
│   └── package.json
└── ...
```

每个平台目录包含：

- `bin/opencode`：可执行二进制文件
- `package.json`：平台特定的包信息

## esbuild 配置

### esbuild 特性

Bun.build 底层使用 esbuild，提供以下特性：

1. **极快的构建速度**：使用 Go 语言编写
2. **内置 TypeScript 支持**：无需额外编译步骤
3. **Tree-shaking**：自动移除未使用的代码
4. **代码分割**：支持动态导入分割
5. **Source Maps**：生成完整的源码映射

### 关键配置选项

```typescript
await Bun.build({
  // 构建目标
  target: "bun-linux-x64",

  // 条件导出
  conditions: ["browser"],

  // TypeScript 配置
  tsconfig: "./tsconfig.json",

  // 插件系统
  plugins: [solidPlugin],

  // 源码映射
  sourcemap: "external", // 外部源码映射文件

  // 编译选项
  compile: {
    // 禁用自动加载
    autoloadBunfig: false,
    autoloadDotenv: false,

    // 启用自动加载
    autoloadTsconfig: true,
    autoloadPackageJson: true,

    // 输出文件
    outfile: "dist/opencode",

    // 执行参数
    execArgv: ["--user-agent=opencode/1.0.0", "--use-system-ca", "--"],

    // 平台特定选项
    windows: {}, // Windows 特定配置
  },

  // 入口点
  entrypoints: ["./src/index.ts", "./src/worker.ts"],

  // 全局变量定义
  define: {
    OPENCODE_VERSION: "'1.0.0'",
    NODE_ENV: "'production'",
  },
})
```

### 自定义插件

OpenCode 使用自定义插件来扩展构建功能：

```typescript
// SolidJS 插件
import solidPlugin from "../node_modules/@opentui/solid/scripts/solid-plugin"

// 使用插件
await Bun.build({
  plugins: [solidPlugin],
  // ...其他配置
})
```

## Turborepo monorepo 构建

### Turborepo 配置

项目使用 Turborepo 管理多包依赖和任务编排：

```json
// turbo.json
{
  "$schema": "https://turborepo.com/schema.json",
  "tasks": {
    "typecheck": {},
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**"]
    },
    "opencode#test": {
      "dependsOn": ["^build"],
      "outputs": []
    },
    "@opencode-ai/app#test": {
      "dependsOn": ["^build"],
      "outputs": []
    }
  }
}
```

### 工作空间配置

```json
// package.json (root)
{
  "workspaces": {
    "packages": ["packages/*", "packages/console/*", "packages/sdk/js", "packages/slack"]
  }
}
```

### Turborepo 任务

| 任务名      | 描述                 | 依赖关系            |
| ----------- | -------------------- | ------------------- |
| `typecheck` | 运行所有包的类型检查 | 无                  |
| `build`     | 构建所有包           | `^build` (依赖的包) |
| `test`      | 运行所有包的测试     | `^build`            |

### 运行 Turborepo 任务

```bash
# 运行所有 typecheck 任务
bun turbo typecheck

# 构建所有包（按依赖顺序）
bun turbo build

# 运行所有测试
bun turbo test

# 仅运行特定包的任务
bun turbo build --filter=opencode
bun turbo build --filter=@opencode-ai/app

# 查看任务依赖图
bun turbo build --dry-run
```

### 任务依赖关系

```
build 任务依赖关系：

opencode (core)
  ├── util (shared utilities)
  ├── plugin (plugin system)
  ├── sdk (TypeScript SDK)
      └── opencode (builds after SDK)
  ├── app (Web UI)
      └── sdk
      └── ui
  ├── desktop (Desktop App)
      └── sdk
      └── ui
  └── ...
```

### Turborepo 缓存

Turborepo 自动缓存任务结果：

- **缓存位置**：`.turbo/cache/`
- **缓存键**：基于源文件、环境变量、任务配置
- **缓存策略**：输入未改变时跳过任务

强制清理缓存：

```bash
rm -rf .turbo/cache
bun turbo build --force
```

## Tree-shaking 与代码分割

### Tree-shaking

Bun/esbuild 自动执行 tree-shaking：

```typescript
// input.ts
import { foo } from "./module.js"

console.log(foo)

// 只会打包 foo，bar 会被移除
// module.js
export function foo() {
  return 1
}
export function bar() {
  return 2
}
```

### Tree-shaking 配置

```typescript
await Bun.build({
  // 启用生产模式优化（包括 tree-shaking）
  minify: {
    whitespace: true,
    identifiers: true,
    syntax: true,
  },

  // 移除未使用的导出
  treeShaking: true, // 默认启用
})
```

### 代码分割

Bun 支持动态导入实现代码分割：

```typescript
// 主文件
import("./heavy-module.js").then((module) => {
  module.heavyFunction()
})
```

这将生成单独的 chunk 文件，仅在需要时加载。

### Worker 分离

OpenCode 将 worker 代码分离到单独的文件：

```typescript
// build.ts
const workerPath = "./src/cli/cmd/tui/worker.ts"

await Bun.build({
  entrypoints: [
    "./src/index.ts", // 主入口
    parserWorker, // 解析器 worker
    workerPath, // TUI worker
  ],
})
```

### 条件导出

使用 `conditions` 选择不同的导出路径：

```typescript
await Bun.build({
  conditions: ["browser"], // 使用浏览器特定导出
})
```

在 `package.json` 中定义：

```json
{
  "exports": {
    ".": "./src/index.ts",
    "./browser": "./src/browser.ts",
    "./node": "./src/node.ts"
  }
}
```

## 生产环境优化

### 压缩

Bun.build 内置压缩选项：

```typescript
await Bun.build({
  minify: {
    whitespace: true, // 移除空白字符
    identifiers: true, // 缩短变量名
    syntax: true, // 简化语法
  },
})
```

### 目标版本

根据目标平台设置合适的 ECMAScript 版本：

```typescript
await Bun.build({
  target: "esnext", // 最新 ES 特性
  // 或
  target: "es2022", // 特定版本
})
```

### 源码映射

生产环境应使用外部源码映射：

```typescript
await Bun.build({
  sourcemap: "external", // 生成单独的 .map 文件
})
```

构建产物：

```
dist/
├── opencode
└── opencode.map  # 外部源码映射
```

### 环境变量

在构建时注入环境变量：

```typescript
await Bun.build({
  define: {
    "process.env.NODE_ENV": JSON.stringify("production"),
    "process.env.VERSION": JSON.stringify("1.0.0"),
  },
})
```

使用 Bun 的内置变量：

```typescript
await Bun.build({
  define: {
    "import.meta.env.PROD": "true",
  },
})
```

## 常见构建任务

### 开发模式构建

```bash
# 运行核心包开发服务器
cd packages/opencode
bun run --conditions=browser ./src/index.ts serve

# 运行 Web 应用开发服务器
cd packages/app
bun dev

# 运行桌面应用
cd packages/desktop
bun dev
```

### 生产构建

```bash
# 构建所有包
bun turbo build

# 构建特定包
bun turbo build --filter=opencode

# 构建所有平台二进制
cd packages/opencode
bun run build
```

### 类型检查

```bash
# 检查所有包
bun turbo typecheck

# 检查特定包
bun turbo typecheck --filter=opencode
```

### 清理构建产物

```bash
# 清理 Bun 缓存
rm -rf node_modules/.cache

# 清理 Turborepo 缓存
rm -rf .turbo/cache

# 清理构建输出
rm -rf dist
```

### 依赖管理

```bash
# 安装所有依赖
bun install

# 安装特定平台依赖
bun install --os="*" --cpu="*" @opentui/core@latest

# 更新依赖
bun update

# 检查过时依赖
bun outdated
```

## 故障排除

### 构建失败

**问题**：构建失败，提示找不到模块

```bash
# 清理依赖并重新安装
rm -rf node_modules bun.lockb
bun install

# 清理 Turborepo 缓存
rm -rf .turbo/cache
bun turbo build
```

**问题**：构建超时

```bash
# 增加内存限制
NODE_OPTIONS="--max-old-space-size=4096" bun turbo build

# 使用单线程构建
bun turbo build --concurrency=1
```

### Tree-shaking 不工作

**问题**：未使用的代码未被移除

**解决方案**：

1. 确保 `package.json` 中正确设置 `sideEffects`

```json
{
  "sideEffects": false, // 无副作用，可安全 tree-shaking
  // 或
  "sideEffects": ["./some-file.js"] // 这些文件有副作用
}
```

2. 确保使用 ES 模块

```json
{
  "type": "module"
}
```

### Source Maps 错误

**问题**：调试时源码映射不正确

**解决方案**：

```typescript
await Bun.build({
  sourcemap: "external", // 使用外部源码映射
  // 确保源码文件路径正确
  root: path.resolve(__dirname),
})
```

### Turborepo 缓存问题

**问题**：代码改变但任务未重新运行

**解决方案**：

```bash
# 强制重新运行任务
bun turbo build --force

# 或清理缓存
rm -rf .turbo/cache
```

### 平台特定构建问题

**问题**：特定平台构建失败

**解决方案**：

```bash
# 构建当前平台
bun run build --single

# 检查目标平台支持
bun --version

# 使用兼容性目标
OPENCODE_LIBC="glibc" bun run build
```

## 总结

OpenCode 的构建系统结合了 Bun、esbuild、Vite 和 Turborepo 的优势：

- **Bun.build**：快速的原生构建 API，支持多平台
- **esbuild**：底层打包引擎，提供 tree-shaking 和代码分割
- **Turborepo**：monorepo 任务编排，缓存优化
- **Vite**：Web 应用的现代开发体验

这种多层构建架构确保了：

- ✅ 快速的构建速度
- ✅ 优化的生产输出
- ✅ 高效的开发工作流
- ✅ 跨平台支持
