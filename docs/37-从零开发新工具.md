## 需求分析

### 业务需求

假设我们的团队需要在开发过程中频繁查询天气信息，例如：

- 了解目标城市的天气状况
- 规划户外测试活动
- 调试与天气相关的功能

当前痛点：

1. 需要打开浏览器查询天气
2. 无法在 OpenCode 对话中直接获取天气信息
3. 没有统一的天气数据格式

### 功能需求

基于以上分析，我们定义以下功能需求：

| 需求编号 | 需求描述             | 优先级 |
| -------- | -------------------- | ------ |
| FR-01    | 支持按城市名查询天气 | 高     |
| FR-02    | 支持按坐标查询天气   | 中     |
| FR-03    | 返回温度、湿度等信息 | 高     |
| FR-04    | 处理 API 错误和异常  | 高     |
| FR-05    | 支持中文和英文城市名 | 中     |

### 非功能需求

| 需求编号 | 需求描述               | 优先级 |
| -------- | ---------------------- | ------ |
| NFR-01   | API 响应时间 < 2 秒    | 高     |
| NFR-02   | 工具执行超时时间 10 秒 | 高     |
| NFR-03   | 提供清晰的错误消息     | 高     |
| NFR-04   | 参数验证通过 Zod 完成  | 高     |

### 技术选型

**API 选择**: Open-Meteo API

- ✅ 免费使用，无需 API Key
- ✅ 支持城市名和坐标查询
- ✅ 支持多语言
- ✅ 响应速度快
- ✅ 稳定可靠

**文档**: https://open-meteo.com/

## 工具设计

### 工具接口设计

基于 OpenCode 的工具系统，我们需要实现 `Tool.Info` 接口：

```typescript
export interface Info<Parameters extends z.ZodType, M extends Metadata = Metadata> {
  id: string // 工具唯一标识
  init: (ctx?: InitContext) => Promise<{
    description: string // 工具描述
    parameters: Parameters // Zod 参数 schema
    execute(
      args,
      ctx,
    ): Promise<{
      // 执行函数
      title: string
      output: string
      metadata: M
      attachments?: MessageV2.FilePart[]
    }>
    formatValidationError?(error): string // 可选的自定义错误格式化
  }>
}
```

### 参数设计

设计工具参数 schema：

```typescript
parameters: z.object({
  location: z.string().describe("城市名称（如：北京、Shanghai）或坐标（如：39.9,116.4）"),
  units: z.enum(["celsius", "fahrenheit"]).default("celsius").describe("温度单位"),
  days: z.coerce.number().min(1).max(7).default(1).describe("预报天数（1-7天）"),
})
```

**参数说明**:

- `location`: 必填，支持城市名或坐标
- `units`: 可选，默认摄氏度
- `days`: 可选，默认1天，最多7天

### 返回值设计

```typescript
{
  title: "北京天气",

  metadata: {
    temperature: 22,
    humidity: 45,
    windSpeed: 3.5,
    conditions: "晴",
    location: "Beijing",
    timestamp: Date.now()

}
```

### 步骤 2: 实现工具

创建 `src/index.ts`:

```typescript
import { Tool } from "@opencode-ai/plugin"
import z from "zod"

// 天气数据接口
interface WeatherData {
  current: {
    temperature_2m: number
    relative_humidity_2m: number
    wind_speed_10m: number
    weather_code: number
  }
  daily?: Array<{
    time: string[]
    temperature_2m_max: number[]
    temperature_2m_min: number[]
  }>
}

// 天气代码映射
const weatherCodes: Record<number, string> = {
  0: "晴",
  1: "多云",
  2: "多云",
  3: "阴",
  45: "雾",
  48: "雾凇",
  51: "小雨",
  53: "中雨",
  55: "大雨",
  61: "小雨",
  63: "中雨",
  65: "大雨",
  71: "小雪",
  73: "中雪",
  75: "大雪",
  80: "阵雨",
  81: "阵雨",
  82: "暴雨",
  95: "雷阵雨",
  96: "雷阵雨",
  99: "雷暴",
}

// 工具定义
export const WeatherTool = Tool.define("weather", {
  description: "查询指定地点的天气信息，支持按城市名称或坐标查询，返回当前天气和预报数据",
  parameters: z.object({
    location: z.string().describe("城市名称（如：北京、Shanghai）或坐标（如：39.9,116.4）"),
    units: z.enum(["celsius", "fahrenheit"]).default("celsius").describe("温度单位"),
    days: z.coerce.number().min(1).max(7).default(1).describe("预报天数（1-7天）"),
  }),

  // 自定义验证错误格式化
  formatValidationError(error) {
    const issues = error.issues
      .map((issue) => {
        const field = issue.path.join(".")
        const message = issue.message
        return `❌ 参数错误 [${field}]: ${message}`
      })
      .join("\n")

    return `参数验证失败：\n${issues}\n\n请检查输入并重试。`
  },

  async execute(args, ctx) {
    const startTime = Date.now()

    try {
      // 1. 解析位置（城市名或坐标）
      let latitude: number
      let longitude: number

      if (args.location.includes(",")) {
        // 坐标格式
        const [lat, lng] = args.location.split(",").map(Number)
        if (isNaN(lat) || isNaN(lng)) {
          throw new Error(`无效的坐标格式：${args.location}`)
        }
        latitude = lat
        longitude = lng
      } else {
        // 城市名称，使用地理编码 API
        const geoUrl = `https://geocoding-api.open-meteo.com/v1/search?name=${encodeURIComponent(args.location)}&count=1&language=zh`
        const geoResponse = await fetch(geoUrl)

        if (!geoResponse.ok) {
          throw new Error(`地理编码 API 错误: ${geoResponse.status}`)
        }

        const geoData = await geoResponse.json()
        if (!geoData.results || geoData.results.length === 0) {
          throw new Error(`未找到城市：${args.location}`)
        }

        latitude = geoData.results[0].latitude
        longitude = geoData.results[0].longitude
      }

      // 2. 查询天气数据
      const weatherUrl = new URL("https://api.open-meteo.com/v1/forecast")
      weatherUrl.searchParams.append("latitude", latitude.toString())
      weatherUrl.searchParams.append("longitude", longitude.toString())
      weatherUrl.searchParams.append("current", "temperature_2m,relative_humidity_2m,wind_speed_10m,weather_code")
      weatherUrl.searchParams.append("timezone", "auto")

      if (args.days > 1) {
        weatherUrl.searchParams.append("daily", "temperature_2m_max,temperature_2m_min")
        weatherUrl.searchParams.append("forecast_days", args.days.toString())
      }

      // 设置超时
      const controller = new AbortController()
      const timeoutId = setTimeout(() => controller.abort(), 10000)

      const weatherResponse = await fetch(weatherUrl.toString(), {
        signal: controller.signal,
      })
      clearTimeout(timeoutId)

      if (!weatherResponse.ok) {
        throw new Error(`天气 API 错误: ${weatherResponse.status}`)
      }

      const weatherData: WeatherData = await weatherResponse.json()

      // 3. 格式化输出
      const current = weatherData.current
      const tempUnit = args.units === "celsius" ? "°C" : "°F"
      const temp = args.units === "fahrenheit" ? (current.temperature_2m * 9) / 5 + 32 : current.temperature_2m

      const weatherCondition = weatherCodes[current.weather_code] || "未知"

      let output = `🌤️ ${args.location} 天气\n\n`
      output += `🌡️ 温度：${Math.round(temp)}${tempUnit}\n`
      output += `💧 湿度：${current.relative_humidity_2m}%\n`
      output += `💨 风速：${current.wind_speed_10m.toFixed(1)} km/h\n`
      output += `☁️ 天气：${weatherCondition}\n`

      // 添加预报
      if (args.days > 1 && weatherData.daily) {
        output += `\n📅 未来预报：\n\n`
        const daily = weatherData.daily
        const count = Math.min(args.days, daily.time.length)

        for (let i = 0; i < count; i++) {
          const date = new Date(daily.time[i]).toLocaleDateString("zh-CN", {
            month: "short",
            day: "numeric",
            weekday: "short",
          })

          const maxTemp =
            args.units === "fahrenheit" ? (daily.temperature_2m_max[i] * 9) / 5 + 32 : daily.temperature_2m_max[i]
          const minTemp =
            args.units === "fahrenheit" ? (daily.temperature_2m_min[i] * 9) / 5 + 32 : daily.temperature_2m_min[i]

          output += `${date}: ${Math.round(minTemp)}-${Math.round(maxTemp)}${tempUnit}\n`
        }
      }

      // 4. 返回结果
      return {
        title: `${args.location} 天气`,
        output,
        metadata: {
          temperature: Math.round(temp),
          humidity: current.relative_humidity_2m,
          windSpeed: current.wind_speed_10m,
          weatherCode: current.weather_code,
          conditions: weatherCondition,
          location: args.location,
          latitude,
          longitude,
          units: args.units,
          days: args.days,
          timestamp: Date.now(),
          duration: Date.now() - startTime,
        },
      }
    } catch (error) {
      // 处理超时
      if (error instanceof Error && error.name === "AbortError") {
        throw new Error(`请求超时：天气 API 响应时间过长（超过10秒）`)
      }

      // 处理网络错误
      if (error instanceof TypeError && error.message.includes("fetch")) {
        throw new Error(`网络错误：无法连接到天气 API，请检查网络连接`)
      }

      // 重新抛出其他错误
      throw error
    }
  },
})

export default WeatherTool
```

describe("WeatherTool", () => {

### 示例 1: 简单文件读取工具

创建一个简单的文件统计工具：

```typescript
import { Tool } from "@opencode-ai/plugin"
import z from "zod"
import path from "path"
import { Bun } from "bun"

export const FileStatsTool = Tool.define("file-stats", {
  description: "统计文件的行数、字符数和字数",
  parameters: z.object({
    filePath: z.string().describe("文件路径（相对或绝对路径）"),
  }),

  async execute(args, ctx) {
    const startTime = Date.now()

    try {
      // 1. 解析路径
      let filepath = args.filePath
      if (!path.isAbsolute(filepath)) {
        filepath = path.join(process.cwd(), filepath)
      }

      // 2. 请求权限
      await ctx.ask({
        permission: "read",
        patterns: [filepath],
        always: ["*"],
        metadata: { operation: "stats", file: filepath },
      })

      // 3. 读取文件
      const file = Bun.file(filepath)
      if (!(await file.exists())) {
        throw new Error(`文件不存在: ${filepath}`)
      }

      const content = await file.text()

      // 4. 统计信息
      const lines = content.split("\n").length
      const chars = content.length
      const words = content
        .trim()
        .split(/\s+/)
        .filter((w) => w.length > 0).length

      // 5. 返回结果
      return {
        title: path.basename(filepath),
        output:
          `📊 ${path.basename(filepath)} 统计\n\n` +
          `📝 行数: ${lines}\n` +
          `🔤 字符数: ${chars}\n` +
          `📖 字数: ${words}`,
        metadata: {
          lines,
          chars,
          words,
          filepath,
          duration: Date.now() - startTime,
        },
      }
    } catch (error) {
      throw new Error(`文件统计失败: ${error.message}`)
    }
  },
})

export default FileStatsTool
```

### 示例 2: HTTP 请求工具

创建一个通用的 HTTP 请求工具：

```typescript
import { Tool } from "@opencode-ai/plugin"
import z from "zod"

export const HttpRequestTool = Tool.define("http-request", {
  description: "发送 HTTP 请求并返回响应",
  parameters: z.object({
    url: z.string().url().describe("请求的 URL"),
    method: z.enum(["GET", "POST", "PUT", "DELETE", "PATCH"]).default("GET").describe("HTTP 方法"),
    headers: z.record(z.string()).optional().describe("请求头"),
    body: z.string().optional().describe("请求体（JSON 字符串）"),
    timeout: z.coerce.number().default(10000).describe("超时时间（毫秒）"),
  }),

  async execute(args, ctx) {
    const startTime = Date.now()

    try {
      // 1. 构建请求选项
      const options: RequestInit = {
        method: args.method,
        headers: {
          "Content-Type": "application/json",
          ...args.headers,
        },
      }

      // 2. 添加请求体
      if (args.body && ["POST", "PUT", "PATCH"].includes(args.method)) {
        options.body = args.body
      }

      // 3. 设置超时
      const controller = new AbortController()
      const timeoutId = setTimeout(() => controller.abort(), args.timeout)

      // 4. 发送请求
      const response = await fetch(args.url, {
        ...options,
        signal: controller.signal,
      })
      clearTimeout(timeoutId)

      // 5. 解析响应
      const contentType = response.headers.get("content-type") || ""
      let responseBody: string

      if (contentType.includes("application/json")) {
        const data = await response.json()
        responseBody = JSON.stringify(data, null, 2)
      } else {
        responseBody = await response.text()
      }

      // 6. 返回结果
      return {
        title: `${args.method} ${args.url}`,
        output:
          `📡 HTTP ${args.method} ${args.url}\n\n` +
          `状态码: ${response.status}\n` +
          `Content-Type: ${contentType}\n\n` +
          `响应体:\n${responseBody}`,
        metadata: {
          status: response.status,
          statusText: response.statusText,
          contentType,
          duration: Date.now() - startTime,
        },
      }
    } catch (error) {
      if (error.name === "AbortError") {
        throw new Error(`请求超时（${args.timeout}ms）`)
      }
      throw new Error(`HTTP 请求失败: ${error.message}`)
    }
  },
})

export default HttpRequestTool
```

### Q2: Zod 验证失败但没有清晰的错误消息

**解决方案**: 添加 `formatValidationError` 方法

```typescript
formatValidationError(error) {
  const issues = error.issues.map((issue) => {
    const field = issue.path.join(".") || "root"
    return `字段 "${field}": ${issue.message}`
  }).join("\n")
  return `参数验证失败:\n${issues}`
}
```

### Q3: 工具执行超时

**解决方案**:

1. 增加 `timeout` 参数
2. 使用 AbortSignal 处理取消
3. 添加重试逻辑

```typescript
const controller = new AbortController()
const timeoutId = setTimeout(() => controller.abort(), args.timeout || 10000)

try {
  const result = await fetch(url, { signal: controller.signal })
  return result
} finally {
  clearTimeout(timeoutId)
}
```
